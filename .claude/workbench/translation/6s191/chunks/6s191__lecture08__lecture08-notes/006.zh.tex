\section{Model Merging：无需训练的模型增强}

\subsection{基本概念}

Model Merging 是一种将多个模型的参数直接组合的技术，\textbf{无需额外训练}。最初被视为"玩笑"，但现在已被每家 LLM 公司采用。

核心思想：取多个经过不同 fine-tuning 的同架构模型，通过数学操作（如加权平均）合并其参数，得到一个综合多方优势的新模型。

\begin{warningbox}{Model Merging 的限制条件}
\begin{itemize}
    \item 只能合并\textbf{相同架构、相同规模}的模型（如只能 Llama 3 合并 Llama 3，不能跨代合并）
    \item 建议使用\textbf{全精度}模型进行合并——量化模型的精度损失会传播到合并结果
    \item 选择合适的权重和参数更像是"炼金术"而非严格科学——需要反复实验
\end{itemize}
\end{warningbox}

\subsection{主要合并技术}

\subsubsection{SLERP (Spherical Linear Interpolation)}

SLERP 在球面上进行插值（而非直线插值），通常比简单的线性平均产生更好的合并效果。

$$\text{SLERP}(\mathbf{p}_0, \mathbf{p}_1; t) = \frac{\sin((1-t)\Omega)}{\sin\Omega}\mathbf{p}_0 + \frac{\sin(t\Omega)}{\sin\Omega}\mathbf{p}_1$$

其中 $\Omega = \arccos(\mathbf{p}_0 \cdot \mathbf{p}_1 / \|\mathbf{p}_0\| \|\mathbf{p}_1\|)$，$t \in {[}0, 1{]}$ 为插值系数。

特点：简单可靠，在开源社区非常流行；但\textbf{只能合并两个模型}。

\subsubsection{DARE + TIES}

更高级的合并技术，可处理两个以上的模型：

\begin{itemize}
    \item \textbf{DARE (Drop And REscale)}：随机剪枝并重新缩放源模型的参数
    \item \textbf{TIES (TrIm, Elect Sign, merge)}：保留最显著的参数，并通过 \textbf{sign consensus}（符号一致性）解决参数正负相消的问题
\end{itemize}

Sign consensus 的动机：若模型 A 的某参数为正、模型 B 的相同参数为负，简单平均得到接近零的结果，实际上丢失了两个模型各自学到的信息。TIES 通过投票机制确定参数符号，避免这种抵消。

\subsection{Model Merging 的实际配置}

使用 \textbf{mergekit} 等工具，通过 YAML 配置文件定义合并方案：

\begin{itemize}
    \item \textbf{density}：控制保留参数的比例（TIES 方法中不保留全部参数）
    \item \textbf{weight}：控制各源模型在合并中的权重（可根据评估分数赋予不同权重）
\end{itemize}

讲者展示了 Daredevil 8B 模型的家族树——通过迭代合并（合并的模型再与其他模型合并）可以构建出复杂的模型谱系，最终产物在多个 benchmark 上超越所有源模型。

\subsection{应用案例：语言特定模型}

以构建芬兰语 LLM 为例的完整流程：

\begin{enumerate}
    \item 在芬兰语原始文本上做 continual pre-training（5-100B tokens）
    \item 在芬兰语 instruction data 上做 SFT
    \item 在芬兰语 preference data 上做 Preference Alignment
    \item 问题：模型芬兰语能力大增，但\textbf{其他所有能力严重退化}
    \item 解决方案：将芬兰语模型与通用 instruct 模型（如 Llama 3 Instruct）合并
    \item 结果：获得一个\textbf{既擅长芬兰语、又保持通用能力}的模型
\end{enumerate}

\begin{importantbox}{Model Merging 的核心价值}
Model Merging 能够将不同模型的专长\textbf{叠加}在一起，而不会牺牲各自的已有能力。这是解决 fine-tuning 过程中"灾难性遗忘"（catastrophic forgetting）问题的一种高效策略，尤其适合语言特定模型、领域特定模型等场景。
\end{importantbox}

\subsection{本章小结}

Model Merging 是一种零训练成本的模型增强技术，通过参数级别的数学操作组合多个模型的优势。SLERP 适合两模型合并，DARE+TIES 支持多模型合并。它是解决 fine-tuning 导致能力退化问题的有力工具。
