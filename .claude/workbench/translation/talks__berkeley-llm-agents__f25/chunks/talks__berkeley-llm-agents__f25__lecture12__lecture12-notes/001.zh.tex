\section{官方幻灯片证据链：Agentic Hybrid System 的安全闭环}

这套 99 页 deck 的核心不是列举攻击名词，而是建立一条端到端因果链：LLM 被嵌入 host、tool、memory、retrieval 与外部环境后，模型输出会变成其他组件的输入，错误或恶意指令因此可能跨边界升级为数据泄露、越权行动、SQL injection 或 remote code execution。防御也必须沿同一链路布置，从模型 hardening 一直延伸到 runtime policy、least privilege、monitoring、information flow 和 provenance。
