\section{引言}

本期继续探索 Qwen3-30B-A3B（MoE）与 Qwen3-32B（Dense）之间的深层对比。上一期从配置和参数量计算入手，本期聚焦于三个更深入的话题：\textbf{等效宽度}（Effective Width）、\textbf{RMSNorm 参数}、以及 FFN/MoE 与 Attention 在计算角色上的根本差异。

\begin{knowledgebox}{Qwen3 全家桶}
Qwen3 提供了一套完整的模型矩阵：不同 size（0.6B 到 235B）、Dense 与 MoE 变体、VR Model 与普通对话模型。它已成为学术界做后训练（Post-training）的标配开源模型。
\end{knowledgebox}
