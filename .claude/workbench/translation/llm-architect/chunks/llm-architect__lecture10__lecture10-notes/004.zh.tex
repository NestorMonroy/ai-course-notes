\section{Decode 阶段}

\subsection{什么是 Decode？}

\begin{importantbox}{Decode = 逐 Token 生成}
Prefill 完成后，模型开始逐 token 生成输出。每步只生成一个新 token：
\begin{itemize}
  \item $Q$ 的长度 = 1（只有当前 token）
  \item $K, V$ 的长度 = 历史长度 $M$（包含所有之前的 token）
  \item 是 \textbf{向量-矩阵乘法}（GEMV）
  \item \textbf{内存带宽密集型}（Memory-bound）
\end{itemize}
\end{importantbox}

\subsection{计算特性}

Decode 阶段的核心计算是 $q \times K^T$（$1 \times d_k$ 乘以 $d_k \times M$），结果为 $1 \times M$ 的向量。

\begin{itemize}
  \item 计算量：$O(M \cdot d_k)$
  \item 但需要从内存加载整个 $K$ 矩阵：$O(M \cdot d_k)$ 的数据量
  \item 计算/内存比 $\approx 1$ $\Rightarrow$ \textbf{内存带宽密集型}
  \item 内存带宽是瓶颈，GPU 算力严重闲置
\end{itemize}

\subsection{本章小结}

Decode 是向量-矩阵乘法（GEMV），内存带宽密集型，瓶颈在内存带宽而非算力。
