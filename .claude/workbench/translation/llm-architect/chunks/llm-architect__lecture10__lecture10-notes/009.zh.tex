\section{总结与延伸}

\begin{enumerate}
  \item Prefill = GEMM = 计算密集型；Decode = GEMV = 内存带宽密集型
  \item KV-Cache 避免了 Decode 时重复计算 $K, V$，但消耗大量显存
  \item GQA 通过减少 KV heads 压缩 KV-Cache，是推理效率的关键
  \item 后续将介绍 MHA（Massive Head Attention）和 KiMi 发布的 Attention Allocation 等新工作
\end{enumerate}

\subsection{拓展阅读}
\begin{itemize}
  \item Apple M5 Max 的统一内存架构对 LLM 推理的影响
  \item SGLang：高效 LLM 推理框架
  \item FlashAttention：加速 Prefill 阶段的 Attention 计算
  \item Paged Attention：优化 KV-Cache 的显存管理
\end{itemize}
