Moonshot AI presentó formalmente K2.5 el 25/26 de enero de 2026, y el docente dice desde la apertura: \textit{``Dive into Kimi K2.5 这篇庞杂的文章''}, y ubica todo este curso como un recorrido integral desde los datos y el algoritmo hasta la infraestructura. También se menciona en esta misma línea de tiempo la versión de Gemini 3 Flash agent vision, lanzada dos días después, con el fin de mostrar que el multimodal nativo y el agente visual no son hechos aislados.

\begin{knowledgebox}{Tres hilos de lectura}
\begin{itemize}
    \item \textbf{Data}: indagar cómo se define, muestrea y sintetiza cada nuevo dominio de datos; un nuevo domain significa una nueva capacidad.
    \item \textbf{Algorithm}: ¿quién evalúa la respuesta del modelo? Cómo el GRM y el entrenamiento de varias etapas cooperan para estabilizar las tareas open-ended.
    \item \textbf{Infra}: cómo los Critical Steps, el agent swarm en paralelo y la canalización de evaluación gestionan juntos el compute y la latency.
\end{itemize}
\end{knowledgebox}

\subsection{Resumen de la sección}
La guía de lectura de K2.5 parte de ``Read the tech report'' y deja claro que seguiremos la ruta de implementación de Visual Agency Intelligence desde tres perspectivas: datos, algoritmo y arquitectura, tomando este guion como una versión anotada del informe técnico.
