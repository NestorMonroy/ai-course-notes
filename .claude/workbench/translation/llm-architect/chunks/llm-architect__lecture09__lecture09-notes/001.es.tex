Moonshot AI presentó oficialmente K2.5 el 25/26 de enero de 2026, y el docente dice desde la apertura: \textit{``Dive into Kimi K2.5 这篇庞杂的文章''}, y sitúa todo este curso como un recorrido integral que va de los datos y el algoritmo a la infraestructura. También se menciona en esta línea de tiempo la versión de Gemini 3 Flash con agent vision, publicada dos días después, con el fin de mostrar que la multimodalidad nativa y la agencia visual no son eventos aislados.

\begin{knowledgebox}{Tres hilos de lectura}
\begin{itemize}
    \item \textbf{Data}: preguntar cómo se define, muestrea y sintetiza cada nuevo dominio de datos; un nuevo domain implica una nueva capacidad.
    \item \textbf{Algorithm}: ¿quién evalúa las respuestas del modelo? Cómo el GRM y el entrenamiento de múltiples etapas cooperan para estabilizar las tareas open-ended.
    \item \textbf{Infra}: cómo los Critical Steps, el agent swarm en paralelo y el pipeline de evaluación administran juntos el compute y la latency.
\end{itemize}
\end{knowledgebox}

\subsection{Resumen de la sección}
La introducción a K2.5 parte de ``Read the tech report'' y deja claro que vamos a seguir la ruta de implementación de Visual Agency Intelligence desde las perspectivas de datos, algoritmo y arquitectura, tomando este guión como una versión anotada del informe técnico.
