\section{Evaluation 案例与复现}

\subsection{典型 Evaluation Case}
讲师列出的 evaluation list 里包含 replicating Apple iPad Air site、视频描述、GUI 操作等任务，所有任务都会拆成视觉/文本/工具三个 subagent，然后回到 Allcastrater 里用 GRM 打分。从讲稿里的 timeline（例如 00:20:50）可以看到，当视觉 agent 抽取界面信息后，文本 agent 立刻补充解释、工具 agent 用命令执行操作，形成一个完整的 Visual Agency 流程。

\begin{knowledgebox}{Evaluation 任务聚焦}
\begin{itemize}
    \item 复现 Apple iPad Air landing page：视觉 agent 捕捉界面、工具 agent 生成 CSS/HTML、文本 agent 提供说明。
    \item 视频描述 benchmark：多个 agent 在 single loop 里并行提取 frame、生成 narrative、对齐 timestamps。
    \item GUI 操作：VRL 和 GUI agents 共同追踪点击、滑动等 critical steps，确保 tool trace 可复现。
\end{itemize}
\end{knowledgebox}

\subsection{复现检查清单}
为了把每个 evaluation case 复现出来，我们把手头素材整理成 checklist：Data + Algorithm + Agent + Infra 四条脉络，每条脉络都要提供 quote、figure、box 与 summary table，最后用 `summary table` 汇总洞见。每个 figure 都标注 \verb|\protect\footnotemark| 并写具体 timecode，确保编写的笔记在 audit 中可以追溯。

\begin{importantbox}{复现笔记 Checklist}
\begin{enumerate}
    \item 重写 metadata（作者、日期、时长、平台），确认没有 placeholder。
    \item 从 \texttt{subs\_clean} 抽取段落，按教学逻辑排序并插入 boxes 与 quotes。
    \item 每个 section 给出 figure timecode / slides 页码并写 summary table，确保 evidence 可验证。
    \item 运行 xelatex 两轮，确认 PDF page count 与 boxes 数量达标。
\end{enumerate}
\end{importantbox}

\subsection{本章小结}
Evaluation 案例强调了 `critical tasks -> timecode -> evidence` 的流水线；只要按照 checklist 复现每个 benchmark，并把 evidence table、boxes 与 figures 录入笔记，audit 就能快速通过。
