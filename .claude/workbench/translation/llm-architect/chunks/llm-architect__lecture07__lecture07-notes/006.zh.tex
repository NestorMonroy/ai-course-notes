\section{总结与延伸}

\begin{enumerate}
  \item Multi-Head Attention 的不同 Head 自然分化出 Local、Global、Sink 等模式
  \item Attention Sink 是 Softmax 归一化的副产品，第一个 token 充当注意力``垃圾桶''
  \item Gated Attention (NeurIPS Best Paper) 通过门控缓解此问题
  \item 模型可解释性研究只需前向推理即可开展，适合资源有限的研究者
\end{enumerate}
