\section{未来展望与行动建议}

\subsection{未来 12 个月的路线}

Burak 预测未来一年将聚焦两个方向：1) 将 agent 统一到 single platform（不再用碎片化 stack）；2) 提升 governance capability，尤其是 multi-modal output 的 auditability。

\subsection{战略性建议}

\begin{itemize}
    \item 把 agent capability roadmap 写成 multi-layer diagram（capability + policy + Ops）
    \item 在 early stage invest in tool manifest \& prompt atlas，而不是直接 GPT-4 最终 prompt
    \item 采用 `policy-as-code` tooling 让 compliance team 参与 sprint planning
\end{itemize}

\subsection{本章小结}

未来一年会把 attention 从 capability 升级到 governance 与 Operations，提前准备的团队会赢在落地速度。
