\section{引言：企业视角下的 GenAI 趋势}

Burak Gokturk 是 Google 的工程副总裁。本讲不深入算法细节，而是从\textbf{企业市场}的宏观视角审视 GenAI 的发展趋势，为学生和创业者提供实用的方向指引。

\begin{knowledgebox}{从 PhD 到产业的视角转变}
Burak Gokturk 以自己的 PhD 经历开场：当年神经网络被认为``不如 SVM''，训练 50 个病人的 CT 数据需要 42 秒就觉得太慢。如今大模型训练动辄数周。一个有趣的担忧是：训练周期过长导致研究者获取直觉的速度变慢了。
\end{knowledgebox}

\subsection{本章小结}

AI 的发展速度远超预期，从学术界到企业界都在经历范式转变。
