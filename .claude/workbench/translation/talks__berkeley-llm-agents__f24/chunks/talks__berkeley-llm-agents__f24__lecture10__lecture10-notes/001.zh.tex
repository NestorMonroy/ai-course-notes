\section{引言：Agentic AI 的未来}

本讲由两位嘉宾联合呈现：\textbf{Chi Wang}（Microsoft Research，AutoGen 框架核心开发者）介绍 Agentic AI 框架与 AutoGen；\textbf{Jerry Liu}（LlamaIndex 创始人兼 CEO）介绍多模态知识助手的构建。

\subsection{什么是 Agentic AI？}

\begin{importantbox}{Agentic AI 的核心价值}
\begin{enumerate}
    \item \textbf{自然语言接口}：用户用自然语言描述需求，Agent 自动理解并执行
    \item \textbf{自主执行复杂任务}：通过多步推理和工具调用，在最少人类监督下完成任务
    \item \textbf{新型软件架构}：多个 Agent 协作构成模块化、可递归组合的系统
\end{enumerate}
\end{importantbox}

示例展示了 Magentic-One（基于 AutoGen）自动构建网站的全过程：分析任务、安装依赖、多 Agent 协作编写代码、编译运行，甚至在关键代码被删除后能自我修复。

\subsection{本章小结}

Agentic AI 不仅是 LLM 的应用层，更代表了一种全新的软件开发范式——从``编写代码''到``编排 Agent''。
