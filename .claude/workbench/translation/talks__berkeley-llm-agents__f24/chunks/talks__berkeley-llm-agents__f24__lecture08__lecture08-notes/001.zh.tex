\section{引言：从单模型到复合 AI 系统}

Omar Khattab 是 Databricks 的研究科学家，DSPy 框架的创造者。本讲的核心观点：\textbf{单个 LLM 调用不够}——我们需要将多个 LLM 调用、检索、工具组合成\textbf{复合 AI 系统}（Compound AI Systems），并用\textbf{编程}而非手工 prompting 来构建它们。

\begin{importantbox}{从 Demo 到生产}
构建一个令人印象深刻的 AI Demo 从未如此容易（如 ChatGPT），但构建一个\textbf{可靠的}生产系统仍然很难。核心原因：单次 LLM 调用的能力是有限且不可靠的。
\end{importantbox}

\subsection{本章小结}

复合 AI 系统通过组合多个组件，突破了单次 LLM 调用的能力上限。
