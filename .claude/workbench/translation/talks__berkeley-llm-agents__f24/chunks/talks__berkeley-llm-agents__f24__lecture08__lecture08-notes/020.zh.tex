\section{术语表 \& 工具链}

\begin{description}
    \item[Signature] 模块输入/输出声明，DSPy 依赖它构建可组合 pipeline。
    \item[Evidence Matrix] Prompt/response/metric 的日志表格。
    \item[Optimizer] 自动化搜索 prompt/示例的 stack。
    \item[Action Timeline] 记录 pipeline 调整与 owner 的日志。
    \item[MCP] Modular Control Protocol，用于 agent 间的 handshake。
    \item[Tool Descriptor] 描述 tool 可接受参数的 metadata。
    \item[Fallback] 监控触发的回退 prompt / pipeline。
    \item[Metric Drift] 生产环境 metric 下降，通常需 retrain / rollback。
    \item[Governance Log] 记录事件、责任人、复盘结论的文档。
    \item[Evidence Snapshot] 运行时 capture 的 prompt/response/carbon copy，用于回放。
\end{description}

\subsection{本章小结}

术语表与工具链说明让团队在跨职能会议时保持一致的语言，避免 ``每个人理解不同'' 的风险。
