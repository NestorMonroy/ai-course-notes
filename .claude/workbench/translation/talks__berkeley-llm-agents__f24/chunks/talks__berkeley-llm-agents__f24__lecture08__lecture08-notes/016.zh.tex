\section{故障恢复故事}

\subsection{背景}

一次 deployment 后，User feedback spike 告知模型在合规问题上拒答；Evidence Matrix 指向 `VerifyModule` 输出 `score=0.55`。

\subsection{恢复步骤}

\begin{enumerate}
    \item 回滚 optimizer result 到 previous stable commit
    \item 重新生成 fallback prompt，增加 ``if unsure, escalate to human'' 说明
    \item 用 `Action Timeline` 记录 rollback + reason
    \item Trigger QA review to validate new prompt set
\end{enumerate}

\subsection{本章小结}

这起故障恢复展现了 evidence log、Action Timeline 与 governance 文档如何组合，实现快速回滚与复盘。
