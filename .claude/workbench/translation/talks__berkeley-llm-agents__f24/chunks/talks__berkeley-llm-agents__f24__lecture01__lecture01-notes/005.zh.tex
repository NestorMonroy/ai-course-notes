\section{总结与延伸}

这节导论课完成了三件事：定义 LLM Agent 的系统结构、说明为什么 Agent framework 值得单独研究、以及给出整门课的能力地图与项目路线。它的核心信息非常直接：大模型能力已经足够强，但若想进入真实世界任务，关键瓶颈会从``模型会不会说''转向``系统会不会做''。
