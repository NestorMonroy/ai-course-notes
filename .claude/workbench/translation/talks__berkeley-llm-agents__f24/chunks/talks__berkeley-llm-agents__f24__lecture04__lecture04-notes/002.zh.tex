\section{Foundation Agent：从语言到行动}

\subsection{基础模型在 Agent 中的应用}

Jim Fan 提出 \textbf{Foundation Agent} 的概念——利用大规模预训练的基础模型来构建通用 Agent：

\begin{itemize}
    \item \textbf{Voyager}：Minecraft 中的开放世界探索 Agent，使用 GPT-4 作为推理核心，自动发现技能、编写代码、存储到技能库，实现持续学习
    \item \textbf{Eureka}：使用 LLM 自动生成和优化 reward function，在物理仿真中训练灵巧手操作
    \item \textbf{MineDojo}：大规模 Minecraft 知识库和开放世界基准
\end{itemize}

\begin{knowledgebox}{Voyager 的技能库}
Voyager 学会的每个技能（如制作剑、建造房屋）都以可执行代码形式存储。后续任务可以直接调用已有技能，无需从头学习——这是 Agent 长期记忆和持续学习的一个优秀范例。
\end{knowledgebox}

\subsection{本章小结}

Foundation Agent 通过 LLM 的推理和代码生成能力，在虚拟世界中实现了开放世界探索和持续技能学习。
