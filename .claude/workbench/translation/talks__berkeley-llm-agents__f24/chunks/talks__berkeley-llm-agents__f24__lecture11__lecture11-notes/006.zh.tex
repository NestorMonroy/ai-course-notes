\section{新兴应用领域}

\subsection{数字自动化（Digital Automation）}

LLM Agent 开启了全新的应用维度——\textbf{数字自动化}：

\begin{itemize}
    \item \textbf{WebShop}：Agent 在模拟亚马逊网站上执行购物任务（搜索、比较、定制、购买），基于百万级真实商品数据构建。
    \item \textbf{网页交互}：Agent 操作真实网页完成各种任务。
    \item \textbf{SWE-bench}：Agent 给定 GitHub 仓库和 issue，需要理解代码库、编写测试、生成修复补丁——真正的软件工程任务。
\end{itemize}

\subsection{科学发现}

如 CHEM-AI 工作：Agent 分析化学数据、使用工具（Python、搜索引擎），提出新化合物方案，方案在湿实验室中被合成验证——Agent 的动作空间延伸到物理世界。

\subsection{本章小结}

LLM Agent 的应用已从传统 NLP/RL 的问答和游戏扩展到实际的数字自动化和科学发现，这是以往 Agent 范式无法企及的。
