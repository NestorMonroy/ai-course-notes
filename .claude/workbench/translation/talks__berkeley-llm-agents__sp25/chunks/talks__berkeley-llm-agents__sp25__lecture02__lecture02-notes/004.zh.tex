\section{总结与延伸}

\subsection{核心信息}

LLM Agent 在数学发现和科学发现中具有巨大潜力，其优势不仅在于强大的搜索能力和先验知识，更在于\textbf{抽象能力}——发现新概念、构建层次化解决方案。关键设计模式包括：

\begin{enumerate}
    \item \textbf{LLM + 形式化验证}：LLM 生成证明步骤，证明助手提供接地反馈
    \item \textbf{层次化分解}：LLM 进行高级规划和子问题分解
    \item \textbf{概念引导进化}：LLM 抽象和组合高级概念，引导搜索方向
    \item \textbf{Prompt 工程的灵活性}：无需额外训练即可实现质变的能力提升
\end{enumerate}
