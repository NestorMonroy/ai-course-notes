\subsection{关键词速记}
\begin{itemize}
    \item Chunk gating：proof search 中的 token/overlap/latency 策略选择器。
    \item Drift gate：entropy 下降触发 fallback + review。
    \item Trace log：每次 failed proof 的 tactic sequence + human comment。
    \item Knowledge pipeline：log + newsletter + transcript 三角形。
\end{itemize}
\begin{knowledgebox}{关键词速记的作用}
用统一术语帮助新成员快速上手 AlphaProof 的 operational playbook，并配合 governance board 形成反馈闭环。
\end{knowledgebox}

\subsection{本章小结}
AlphaProof 是一个把数学形式化、强化学习与可治理工程实践编织在一起的系统：Lean 提供 sandbox，RL 提供 search-policy 飞轮，治理提供 trace/alert/knowledge，而 newsletter 则让整个团队保持同步。
