\section{第四部分：迈向研究级数学的 AI 辅助}

\subsection{研究级形式化的特殊挑战}

研究级数学的形式化（如 Terence Tao 的 PFR 项目）涉及：
\begin{enumerate}
    \item 创建\textbf{蓝图}（Blueprint）：将证明分解为依赖图
    \item 编写大量\textbf{新定义}和\textbf{辅助引理}
    \item 组装最终定理和证明
\end{enumerate}

\begin{warningbox}{当前基准测试的局限}
主流基准（如 mini-F2F）基于数学竞赛题，具有自包含、依赖标准结果的特点。而真实研究项目中的定理\textbf{依赖于项目特有的新定义和新引理}，这一差距导致在竞赛题上表现优秀的模型在实际项目中可能严重失败。
\end{warningbox}

\subsection{MiniCTX 基准测试}

\begin{importantbox}{MiniCTX：上下文依赖的定理证明基准}
\begin{itemize}
    \item 从真实 Lean 项目（如 Mathlib、PFR）中提取测试定理
    \item 按日期截止选取，可持续更新以领先于模型训练截止日期
    \item 区分文件内依赖和跨文件依赖
    \item 实验表明：在竞赛题上，上下文几乎不影响性能；在真实项目上，\textbf{缺少上下文导致性能断崖式下降}
\end{itemize}
\end{importantbox}

\subsection{实用工具：LLMLean}

LLMLean 是一个 Lean 插件，可连接本地模型（通过 Ollama/LM Studio）或 API 模型（OpenAI、Claude、Gemini 等），在 VS Code 中直接提供经 Lean 验证的证明建议。
