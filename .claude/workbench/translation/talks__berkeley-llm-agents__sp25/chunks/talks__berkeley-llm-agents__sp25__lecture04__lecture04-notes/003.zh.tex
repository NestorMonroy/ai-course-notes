\section{从竞赛数学到前沿数学的鸿沟}

\subsection{当前 LLM 的数学能力局限}

\begin{itemize}
    \item O1/O3 在 AMC/AIME 等预科竞赛上表现出色
    \item Frontier Math 基准包含研究级数学题，O3 解决了 20\%+（但题目被设计为有数值答案）
    \item Terence Tao 评价：O1 仍在最前沿研究数学任务上挣扎
\end{itemize}

\subsection{证明生成的困境}

\begin{warningbox}{LLM 写证明的严重问题}
\begin{itemize}
    \item Putnam 竞赛（本科级）：ChatGPT 大多只得 1--2/10 分
    \item USAMO 评估：所有模型得分约 5\%
    \item 错误类型：不等式方向翻转等``简单''错误，隐藏在长证明中极难检测
\end{itemize}
根本原因：前沿数学\textbf{数据稀缺}且\textbf{证明不可验证}。
\end{warningbox}
