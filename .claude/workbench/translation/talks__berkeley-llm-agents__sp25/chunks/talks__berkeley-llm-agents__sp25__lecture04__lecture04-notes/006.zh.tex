\section{总结与延伸}

\subsection{核心信息}

\begin{enumerate}
    \item 当前 LLM 数学能力主要依赖 SFT 和 RL，受限于数据量和可验证性
    \item 形式化推理（Lean）提供完美验证信号，可缓解数据稀缺和评估困难
    \item LeanDojo 提供了开源的定理证明基础设施
    \item 领域特定方法（如 LiPS）可在特定任务上超越人类和前沿 LLM
    \item 自动形式化（声明和证明）各有独特挑战
\end{enumerate}

\subsection{拓展阅读}
\begin{itemize}
    \item LeanDojo（NeurIPS 2023）：开源定理证明数据和工具
    \item LiPS：不等式证明中的符号+神经混合方法
    \item ``AI for Math'' 立场论文（arXiv）
    \item Frontier Math 基准（Epoch AI）
    \item DeepSeek-R1：RL 训练推理模型
\end{itemize}
