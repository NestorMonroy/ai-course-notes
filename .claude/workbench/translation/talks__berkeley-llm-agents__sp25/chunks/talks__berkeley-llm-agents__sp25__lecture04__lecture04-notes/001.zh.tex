\section{引言：形式推理遇上大语言模型}

本讲由 Meta FAIR 的 Kaiyu Yang 主讲，聚焦于将\textbf{形式推理}（formal reasoning）与大语言模型结合，推动 AI 在数学和验证领域的应用。

\begin{knowledgebox}{为何数学和编程是 LLM 竞赛的核心指标}
\begin{itemize}
    \item 数学和编程是\textbf{复杂推理与规划}的代理指标（proxy）
    \item 推理和规划能力可解锁无限应用（旅行规划、日程管理等）
    \item 数学和编程\textbf{相对容易评估}：数学可检查答案，代码可运行单元测试
\end{itemize}
\end{knowledgebox}
