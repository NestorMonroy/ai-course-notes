\section{训练数学 LLM 的两大技术}

\subsection{监督微调（SFT）}

\begin{enumerate}
    \item 基础模型在互联网规模数据上预训练
    \item 在数学文档（StackOverflow、arXiv 等）上继续预训练 $\to$ 基础数学模型
    \item 在\textbf{带详细解题步骤}的问答数据上微调（可含工具调用，如 Python）
\end{enumerate}

\begin{warningbox}{数据是最大瓶颈}
SFT 管道中最昂贵的部分是数据收集：需要人工标注、清洗和格式转换，无法完全自动化。
\end{warningbox}

\subsection{强化学习（RL）}

当数据集仅有最终答案而没有中间步骤时，可用 RL 训练：
\begin{enumerate}
    \item 模型生成含中间步骤的解答
    \item 对比最终答案与真实答案：正确奖励 1，错误奖励 0
    \item 用 GRPO 等算法优化模型以最大化奖励
\end{enumerate}

\begin{importantbox}{RL 的关键：可验证性}
RL 依赖于可靠的验证信号。数值答案可直接比较，但\textbf{证明题}的正确性如何自动验证？这正是形式化系统的价值所在。
\end{importantbox}
