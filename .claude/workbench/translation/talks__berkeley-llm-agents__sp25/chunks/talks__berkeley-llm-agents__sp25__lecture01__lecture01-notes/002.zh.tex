\section{LLM Agent 系统架构}

\subsection{LLM 安全 vs Agent 安全}

传统 LLM 应用（如 Chatbot）是简单的"文本输入 $\to$ 文本输出"模式。而 LLM Agent 系统更加复杂：

\begin{itemize}
    \item \textbf{观察}（Observe）：从环境中获取信息
    \item \textbf{推理与规划}（Reasoning \& Planning）：利用 LLM 进行决策
    \item \textbf{记忆与检索}（Memory \& Retrieval）：从外部数据库获取数据
    \item \textbf{行动}（Action）：使用工具、执行函数调用，作用于外部环境
    \item \textbf{反馈}（Feedback）：环境提供执行反馈，形成闭环
\end{itemize}

\begin{importantbox}{Agentic 混合系统（Hybrid System）}
Agentic AI 系统是一种\textbf{混合/复合系统}（Hybrid/Compound System），同时包含：
\begin{itemize}
    \item \textbf{符号化组件}（Symbolic Components）：操作系统、浏览器、移动应用等传统程序
    \item \textbf{神经组件}（Neural Components）：大语言模型等，为系统提供智能
\end{itemize}
系统可包含多个符号化组件和多个神经组件（多模型、多子 Agent）。
\end{importantbox}

\subsection{混合系统工作流}

一个典型的 Agentic 混合系统工作流包括：
\begin{enumerate}
    \item \textbf{Host/开发者}准备模型和系统，部署混合系统
    \item \textbf{用户}向系统发送请求
    \item 系统处理请求，组装 Prompt，调用模型
    \item 模型生成输出，与系统其余部分交互
    \item 系统处理输出，与外部世界交互、执行最终动作
    \item 系统向用户返回响应
    \item 系统可持续运行以完成长期任务
\end{enumerate}
