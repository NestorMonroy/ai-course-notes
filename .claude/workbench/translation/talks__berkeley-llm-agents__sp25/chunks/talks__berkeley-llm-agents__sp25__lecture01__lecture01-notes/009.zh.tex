\section{总结与延伸}

\subsection{核心要点}

\begin{enumerate}
    \item Agentic AI 系统是混合系统，安全和安保问题远比单纯的 LLM 复杂
    \item LLM 的输出可作为攻击链的一部分，导致 SQL 注入、RCE、信息泄露等传统安全漏洞
    \item Prompt 注入（直接和间接）是当前所有 LLM 的固有漏洞
    \item 防御需要纵深防御、最小权限和安全设计三大原则的综合应用
    \item 端到端的评估和红队测试对于发现 Agentic 系统的漏洞至关重要
\end{enumerate}

\subsection{拓展阅读}
\begin{itemize}
    \item Dawn Song 的 ICLR 2025 主题演讲（AI 安全与安保综述）
    \item DecodingTrust：LLM 可信度评估框架
    \item AgentPoison：RAG 后门攻击（NeurIPS 2024）
    \item AgentExploit：黑盒 AI Agent 端到端红队测试
    \item 国际 AI 安全报告（Yoshua Bengio 等领导）
\end{itemize}
