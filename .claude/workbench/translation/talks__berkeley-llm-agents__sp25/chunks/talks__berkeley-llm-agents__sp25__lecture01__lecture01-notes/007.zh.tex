\section{AI Agent 在网络安全中的滥用}

\subsection{前沿 AI 对网络安全格局的影响}

AI Agent 不仅是攻击目标，也可能被滥用为攻击工具：
\begin{itemize}
    \item Web Agent 可被滥用对外部 API 发动 DoS 攻击
    \item Coding Agent 可被用于生成更强大的恶意软件
    \item 系统级滥用可能放大模型级滥用的风险
\end{itemize}

\begin{warningbox}{系统应防止模型滥用升级为系统滥用}
一个良好设计的系统应通过各种护栏和防御机制，防止模型级别的滥用（如生成恶意代码）升级为系统级别的滥用（如实际执行恶意操作）。
\end{warningbox}
