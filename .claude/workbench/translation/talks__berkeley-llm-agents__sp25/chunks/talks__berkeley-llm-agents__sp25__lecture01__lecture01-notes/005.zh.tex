\section{评估与风险评估}

\subsection{模型级评估 vs 系统级评估}

模型级评估关注独立模型在特定输入下的行为（如 MMLU、数学基准测试）。Agentic 混合系统需要\textbf{端到端的系统行为评估}，复杂度远高于模型级评估。

Dawn Song 团队的相关工作包括：
\begin{itemize}
    \item \textbf{DecodingTrust}：首个 LLM 可信度综合评估框架（NeurIPS 最佳论文奖、NSA 年度最佳论文奖）
    \item \textbf{MMDT}：多模态基础模型可信度和安全性评估框架（ICLR 2025）
    \item \textbf{Coding Agent 风险评估}（NeurIPS 2024）
\end{itemize}

\subsection{AgentExploit：黑盒 Agent 端到端红队测试}

\begin{importantbox}{AgentExploit 框架}
在黑盒设置下，攻击者仅能控制外部数据源（如网页、文件），不能修改用户查询或访问 Agent 内部结构，且只能获得二元反馈（攻击成功/失败）。

框架采用\textbf{模糊测试}（Fuzzing）方法：
\begin{enumerate}
    \item 从初始种子攻击指令集开始
    \item 对种子进行变异生成新攻击
    \item 将恶意内容注入外部数据源
    \item 获取反馈，优化种子选择和变异策略
\end{enumerate}
实验结果：攻击成功率是手工基线的两倍，且生成的攻击具有可迁移性。
\end{importantbox}
