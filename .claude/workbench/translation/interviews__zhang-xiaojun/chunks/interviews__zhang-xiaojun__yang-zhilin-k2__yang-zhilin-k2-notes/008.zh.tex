\section{一方产品 vs. 第三方生态}

\subsection{两种产品范式}

\begin{importantbox}{模型公司做一方产品的逻辑}
\begin{itemize}
    \item \textbf{第三方范式}：给定一个模型，逆向工程最佳的使用方式（System Prompt、工具设计、Context Engineering），本质是去拟合模型的训练分布
    \item \textbf{一方范式}：先设计好工具和环境，然后在这个环境中训练模型。模型天然在自己的环境中表现最好，无需逆向工程
\end{itemize}
Cloud Code 和 ChatGPT Agent 都是一方产品的代表。月之暗面目前仍以模型为主线，但认为一方产品将是重要趋势。
\end{importantbox}

\subsection{本章小结}

一方产品通过正向设计环境+训练模型，上限更高；第三方产品通过逆向工程模型使用方式，灵活但受限于模型训练分布。未来两种范式将共存互补。
