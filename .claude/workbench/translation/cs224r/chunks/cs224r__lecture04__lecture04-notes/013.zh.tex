\section{公式与调度}

\subsection{Advantage 与 TD 计算公式组合}

\begin{align*}
\delta_t &= r_t + \gamma V_{\phi}(s_{t+1}) - V_{\phi}(s_t) \\
\hat{A}_t^{\lambda} &= \sum_{l=0}^{\infty} (\gamma \lambda)^l \delta_{t+l} \\
V_{\phi}(s_t) &\leftarrow V_{\phi}(s_t) + \alpha_\phi \delta_t \\
\pi_\theta &\leftarrow \pi_\theta + \alpha_\theta \hat{A}_t^{\lambda} \nabla_\theta \log \pi_\theta(a_t|s_t)
\end{align*}

这组公式展示了 actor/critic 之间的信息流： critic 通过 TD error 更新自身，actor 则把预估 advantage 乘以 log probability 做梯度。$\lambda$ 的调度会显著影响 bias-variance tradeoff，建议在 architecture log 中记录每次变化。

\subsection{Policy loss 与 entropy}

\begin{equation*}
\mathcal{L}_\pi = -\mathbb{E} \left[ \min\left( r_t(\theta) \hat{A}_t, \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon)\hat{A}_t \right) \right] - \beta \mathcal{H}(\pi)
\end{equation*}
\begin{equation*}
\mathcal{H}(\pi) = -\sum_a \pi(a|s) \log \pi(a|s)
\end{equation*}

\begin{knowledgebox}{Clip objective 的稳定策略}
The clip objective minimizes whichever term is smaller between the unclipped ratio and the clipped ratio, so when $r_t(\theta)$ leaves the trust region it safely falls back to the clipped variant. Coupling this with the entropy bonus keeps the early-stage exploration from collapsing too quickly.
\end{knowledgebox}

常见的调度方案：
\begin{itemize}
    \item Learning rate anneal：从 $3e-4$ 归零到 $1e-5$，用 cosine decay 保持平滑。
    \item $\lambda$ 调度：early stage 用 0.95，收敛时渐近到 0.99。
    \item Clipping eps：当 KL 超过阈值时减小 $\epsilon$ 并再 warm up。
\end{itemize}

\begin{warningbox}{调度过快的危险}
如果 entropy bonus 迅速衰减到 0，策略很容易陷入 deterministic 的死胡同，特别是在 reward 稀疏的环境。建议保留一个 floor，最低也要留 0.01 的 entropy。
\end{warningbox}

\subsection{本章小结}

公式与调度提供了 Actor-Critic 的数学骨架。从 advantage 到 policy loss，每一项都需要被记录、可热替换，并在调度 log 中对应具体指标。
