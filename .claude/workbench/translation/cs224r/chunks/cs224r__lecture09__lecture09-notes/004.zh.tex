\section{DPO：Direct Preference Optimization}

\subsection{绕过奖励模型}

\begin{importantbox}{DPO 的核心洞察}
RLHF 中带 KL 约束的 RL 问题有\textbf{闭式解}：
$$\pi^*(y \mid x) = \frac{1}{Z(x)} \pi_{\mathrm{ref}}(y \mid x) \exp\left(\frac{1}{\beta} r(x, y)\right)$$

反过来可以将奖励表示为策略的函数：
$$r(x, y) = \beta \log \frac{\pi^*(y \mid x)}{\pi_{\mathrm{ref}}(y \mid x)} + \beta \log Z(x)$$

将此代入 Bradley-Terry 模型，$Z(x)$ 项相消，得到 DPO 损失：
$$\mathcal{L}_{\mathrm{DPO}}(\theta) = -\mathbb{E}_{(x, y_w, y_l)}\left[\log \sigma\left(\beta \log \frac{\pi_\theta(y_w \mid x)}{\pi_{\mathrm{ref}}(y_w \mid x)} - \beta \log \frac{\pi_\theta(y_l \mid x)}{\pi_{\mathrm{ref}}(y_l \mid x)}\right)\right]$$
\end{importantbox}

DPO 的优势：
\begin{itemize}
    \item 不需要训练单独的奖励模型。
    \item 不需要 RL 训练（无需 PPO）。
    \item 只需要标准的监督训练循环。
    \item 训练更稳定、更简单。
\end{itemize}

\subsection{DPO 的直觉}

DPO 损失隐式地做了两件事：
\begin{enumerate}
    \item \textbf{增加}被偏好回答 $y_w$ 的概率。
    \item \textbf{降低}不被偏好回答 $y_l$ 的概率。
\end{enumerate}

权重由 $\sigma$ 函数内部的"隐式奖励差"自动调节。

\begin{knowledgebox}{DPO vs. RLHF}
\begin{itemize}
    \item \textbf{RLHF}：训练奖励模型 $\to$ RL 优化。两阶段，需要 RL 基础设施。
    \item \textbf{DPO}：直接在偏好数据上优化策略。单阶段，只需 SFT 代码。
    \item 理论上 DPO 与 RLHF 优化的是\textbf{同一个目标}。
    \item 实践中 DPO 更简单但可能在某些场景下不如 RLHF 灵活。
\end{itemize}
\end{knowledgebox}

\subsection{实践与参数选择}

DPO 训练过程中几个关键要素：
\begin{itemize}
    \item 选取稳定的 reference policy，通常用 instruction finetuned checkpoint。
    \item 调整 $\beta$ 以控制偏好程度：$\beta$ 越小，策略越接近 reference；越大，则更容易强化偏好。
    \item 采样权重需要兼顾头部和尾部，避免 reward model 只偏好高概率回答。
\end{itemize}

\begin{knowledgebox}{DPO Training Insight}
DPO 把 reward scoring 转换成 logits 差值，因此观察 $\log \pi_\theta / \pi_{\mathrm{ref}}$ shift 就可以直观判断偏好强化程度。
\end{knowledgebox}

\subsection{本章小结}

DPO 通过将 RL 目标的闭式解代入 Bradley-Terry 模型，将偏好优化简化为纯监督学习问题。结合 $\beta$ sweep 与参考策略选择可以在精度与稳定性之间取得平衡。
