\section{总结与延伸}

\begin{enumerate}
    \item 深度 RL 的开放问题横跨问题定义、方法和部署三个层面
    \item 奖励设计（避免 reward hacking）、泛化能力和安全性是最重要的方向
    \item 好的研究从理解问题开始，不是从方法开始
    \item RL 实验需要多种子、强基线和消融实验
    \item 调试 RL 需要系统性的方法，可视化和简单环境验证至关重要
    \item 跨领域融合（RL + LLM, RL + robotics）是当前最活跃的前沿
\end{enumerate}
