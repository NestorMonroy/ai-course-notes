\section{课程回顾：算法分类总览}

本讲开头，Chelsea Finn 对课程迄今为止讨论过的所有算法做了一个高层回顾。

\begin{importantbox}{算法分类框架}
\begin{itemize}
    \item \textbf{在线 (Online) vs 离线 (Offline)}：在线算法允许在训练中持续与环境交互收集数据；离线算法仅使用给定的固定数据集。
    \item \textbf{Online 类别下}：
    \begin{itemize}
        \item On-policy RL：仅使用当前策略产生的数据（如 REINFORCE, PPO）
        \item Off-policy RL：可以使用历史策略的数据（如 SAC, TD3）
    \end{itemize}
    \item \textbf{Offline 类别下}：
    \begin{itemize}
        \item Imitation Learning：行为克隆 (BC)、DAgger
        \item Offline RL：CQL 等约束策略不偏离数据分布的方法
    \end{itemize}
\end{itemize}
\end{importantbox}
