\section{总结与延伸}

\subsection{关键 Takeaways}

\begin{importantbox}{核心要点}
\begin{enumerate}
    \item \textbf{语义分割是像素级分类}：编码器-解码器 + 跳跃连接（U-Net）是经典范式
    \item \textbf{上采样方法的选择很重要}：从不可学习的插值到可学习的转置卷积，表达力逐步增强
    \item \textbf{目标检测的三代方法}：两阶段（R-CNN 系列）$\rightarrow$ 单阶段（YOLO）$\rightarrow$ Transformer（DETR）
    \item \textbf{实例分割 = 检测 + 分割}：Mask R-CNN 中 RoI Align 的精确对齐是关键
    \item \textbf{YOLO 仍是工业首选}：简单、快速、不断迭代，适合实时应用
    \item \textbf{DETR 消除了手工组件}：不需要锚框、不需要 NMS，但训练成本高
    \item \textbf{可视化是信任的基础}：显著性图和 Grad-CAM 不仅是研究工具，更是模型部署前的必要验证手段
    \item \textbf{Transformer 天然可解释}：注意力权重直接反映模型关注区域，但也不能过度解读
\end{enumerate}
\end{importantbox}
