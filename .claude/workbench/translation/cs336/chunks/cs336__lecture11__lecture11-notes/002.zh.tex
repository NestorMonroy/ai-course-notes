\subsection{模型概述}

Cerebras GPT 是一个大型模型家族，涵盖 0.1B 到 13B 参数规模，使用 Chinchilla 配方训练（即 token 数与参数数的比值大致为最优比例）。

\subsection{MuP 的首次大规模公开验证}

Cerebras GPT 的核心贡献在于它是\textbf{最早公开验证 MuP 有效性}的大规模模型之一。

\begin{figure}[H]
\centering
\includegraphics[width=0.95\textwidth]{slides-images/slide-004.jpg}
\caption{Cerebras GPT 的 scaling 曲线：蓝色为标准参数化（SP），橙色为 MuP 参数化。MuP 版本的 scaling 更加平滑，更接近预测值\protect\footnotemark}
\end{figure}
\footnotetext{Slides 第5页。}

\begin{importantbox}{MuP 带来更可预测的 Scaling}
使用标准参数化（SP）时，实际性能围绕 scaling law 预测值有较大振荡——这是因为不同规模的模型需要不同的学习率，而手动调优不可能完美。使用 MuP 后，振荡显著减小，实际性能更接近 scaling law 的预测曲线。
\end{importantbox}

\subsection{MuP 实现细节}

Cerebras 团队在论文附录中提供了一张非常实用的对照表，清楚列出了标准参数化（SP）和 MuP 之间的具体差异。

\begin{figure}[H]
\centering
\includegraphics[width=0.95\textwidth]{slides-images/slide-005.jpg}
\caption{SP vs MuP 参数对照表：非 embedding 参数初始化缩放 $1/\text{width}$，每层学习率也按 width 缩放\protect\footnotemark}
\end{figure}
\footnotetext{Slides 第6页。}

MuP 的实践要点可以简单概括为：
\begin{itemize}
    \item \textbf{初始化}：非 embedding 参数按 $1/\text{width}$ 缩放
    \item \textbf{学习率}：每层学习率按 $1/\text{width}$ 缩放（对 Adam 优化器）
    \item \textbf{Embedding}：保持常数缩放
\end{itemize}

\subsection{小模型代理搜索策略}

\begin{figure}[H]
\centering
\includegraphics[width=0.95\textwidth]{slides-images/slide-006.jpg}
\caption{Cerebras GPT 的超参数搜索策略：在 40M 参数的代理模型上进行大规模超参数搜索，然后通过 MuP 将结果迁移到更大模型\protect\footnotemark}
\end{figure}
\footnotetext{Slides 第7页。}

Cerebras 团队将模型缩小到仅 40M 参数，在此规模上进行广泛的超参数搜索，然后利用 MuP 的超参数迁移特性将最优配置放大到 13B 规模。这一策略实现了约 \textbf{5x 的计算节省}。

\begin{warningbox}{小模型代理搜索的局限性}
将实验缩小到 40M 参数是非常激进的做法。对于训练真正巨大的模型（如数百亿参数），这种程度的缩小是否仍然可靠尚不确定。但这一策略在 Cerebras GPT、MiniCPM 和 DeepSeek 中都有不同形式的体现——训练较小的代理模型，然后尝试稳定地放大。
\end{warningbox}

\subsection{本章小结}

Cerebras GPT 提供了 MuP 的首次大规模公开验证，证明了通过合理的参数化可以使 scaling 更加可预测。其核心策略是：小规模搜索超参数 + MuP 迁移到大规模，从而大幅减少了超参数调优的计算开销。
