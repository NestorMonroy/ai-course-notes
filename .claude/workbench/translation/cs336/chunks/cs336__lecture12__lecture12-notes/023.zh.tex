\section{总结与延伸}

\subsection{本章小结}

把这一讲压缩成最后几条经验法则，就是：
\begin{itemize}
    \item 评估首先是目标定义问题。
    \item 不同目标对应不同 benchmark。
    \item 绝对分数很重要，但相对排序、成本和鲁棒性同样重要。
    \item 任何 benchmark 都有局限，尤其是在数据污染、饱和和 judge bias 上。
    \item 真正好的评估要能推动模型开发，而不是只让表格更好看。
\end{itemize}

\begin{importantbox}{最后一句更实用的话}
当你看到一个很漂亮的 leaderboard，先别急着相信分数，先问：它到底在测什么，它没测什么，它是模型榜，还是系统榜，还是方法榜？
\end{importantbox}
