\section{一个更完整的 benchmark 选择指南}

如果你要给一个新模型选评估方案，可以按下面的顺序问：
\begin{enumerate}
    \item 我想测知识、推理、对话、工具、还是安全？
    \item 我关心的是模型本身，还是整个系统？
    \item 我需要绝对分数，还是相对排序？
    \item 我在乎成本吗？
    \item 我能否接受真人 judge 或 LLM judge？
    \item 我是否担心污染、过拟合或 benchmark 饱和？
\end{enumerate}

\begin{importantbox}{一个实用原则}
先用最小代价找到能回答问题的评估，再去追求更复杂的评估。不要反过来。
\end{importantbox}

\begin{knowledgebox}{评估设计的工程感}
评估不是收集分数，而是设计实验。像做实验一样，你要控制变量、定义假设、记录条件，并且诚实地汇报失败和限制。
\end{knowledgebox}
