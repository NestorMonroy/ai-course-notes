\section{后续预告：下一讲会讲什么}

本讲最后把课程推进到下一步：tokenization。
课程接下来会从最基础的部分开始，逐步把一个语言模型系统搭起来。
下一讲的重点会是 PyTorch 的基本积木、资源账本，以及最小可运行 pipeline 的关键组件。

\begin{warningbox}{你应该带走的三句话}
\begin{enumerate}
    \item 这门课不是教你“调用模型”，而是教你“构建模型”。
    \item 真正有价值的是能随着规模继续成立的算法和系统。
    \item 理解语言模型，必须把数据、系统和模型一起看。
\end{enumerate}
\end{warningbox}
