\section{课程安排与作业}

讲师在本讲中也给出了课程 logistics 的信息。
课程作业围绕五个方向展开，对应课程的五大模块：
\begin{itemize}
    \item 基础：实现 tokenizer、Transformer、损失函数、优化器和训练循环。
    \item 系统：实现 kernel、分布式训练、状态切分和性能分析。
    \item 规模律：在小规模实验上拟合预测大规模表现。
    \item 数据：从 Common Crawl 处理出适合训练的数据。
    \item 对齐：实现监督微调和偏好优化。
\end{itemize}

课程强调几件事：
\begin{itemize}
    \item 没有大量脚手架代码，但会提供测试和接口。
    \item 先在本地验证正确性，再上集群做 benchmark。
    \item 一些作业有 leaderboard，目标是固定预算下做得更好。
    \item AI 工具可以用，但会削弱学习效果，需自己权衡。
\end{itemize}
