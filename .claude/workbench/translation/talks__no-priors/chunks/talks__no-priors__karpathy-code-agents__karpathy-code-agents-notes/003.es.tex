\section{Claw: la capa de persistencia del agente}

\subsection{Dobby the Elf Claw}

Karpathy compartió su experimento con claw (agente persistente): «Dobby the Elf Claw» es el sistema que construyó para la automatización de su hogar:

\begin{itemize}
    \item El agente escanea automáticamente la red local, descubre el sistema de audio Sonos y le aplica ingeniería inversa a su API
    \item De la misma manera toma el control de la iluminación, el HVAC, las cortinas y el control de la piscina/spa
    \item Analiza el video de las cámaras de seguridad mediante el modelo Quinn y, al detectar cambios, envía una notificación por WhatsApp (por ejemplo, «el camión de FedEx acaba de detenerse frente a la puerta»)
    \item Toda la interacción se realiza en lenguaje natural a través de WhatsApp: «Dobby, sleepy time» apaga todas las luces
\end{itemize}

\begin{knowledgebox}{De seis apps a un solo WhatsApp}
Karpathy antes usaba seis apps distintas para administrar su hogar inteligente, y ahora Dobby las reemplaza por completo. Esto señala un problema más profundo: \textbf{es posible que gran parte de las apps de la App Store no debieran existir}. Deberían ser solo API endpoints, que un agente invoque y orqueste a manera de «pegamento inteligente».
\end{knowledgebox}

\subsection{De Claw al mundo agent-first}

\begin{importantbox}{La refactorización de la industria del software}
El cliente de un agente ya no es un ser humano, sino otro agente. La industria necesita refactorizarse de la «human-first UI» a la «agent-first API». Karpathy considera que esta refactorización será sustancial: la treadmill, el hogar inteligente y las distintas herramientas de SaaS deberían exponer una API en lugar de construir una UI.
\end{importantbox}

\begin{knowledgebox}{Las cinco innovaciones de Open Claw}
Karpathy elogia enormemente el Open Claw de Peter y considera que innova simultáneamente en cinco direcciones:
\begin{enumerate}
    \item \textbf{Soul Document}: una personalidad de agente diseñada con esmero (compelling personality)
    \item \textbf{Memory System}: un sistema de memoria más sofisticado que la context compaction predeterminada
    \item \textbf{Persistence}: un loop que se ejecuta de manera continua sin depender de la interacción del usuario
    \item \textbf{Punto de entrada de WhatsApp}: un portal unificado de interacción en lenguaje natural
    \item \textbf{Ajuste de personalidad}: como el «praise calibration» de Claude, que hace que el usuario sienta que los elogios son sinceros
\end{enumerate}
\end{knowledgebox}
