\section{总结与延伸}

\subsection{核心洞察}

\begin{enumerate}
    \item \textbf{编程范式已经改变}：自 2024 年 12 月起，前沿开发者的工作方式从"写代码"变为"调度 agent"。瓶颈从打字速度转移到 token 吞吐量和 agent 编排能力
    \item \textbf{Everything is skill issue}：当前工具的能力远超大多数人的利用程度。失败往往不是工具不行，而是使用方式不对
    \item \textbf{Auto research 已经有效}：在可验证指标的领域，自动化研究循环已展示出超越人类研究者的潜力
    \item \textbf{移除自己作为瓶颈}：最大化 leverage 意味着最小化人类在循环中的参与——"arrange it once and hit go"
    \item \textbf{Agent-first 重构}：软件行业需要从 human-first UI 重构为 agent-first API
    \item \textbf{模型 jaggedness 是根本特征}：RL 只优化可验证领域，off-rails 行为停滞不前
    \item \textbf{开源作为制衡}：闭源领先半年、开源持续追赶是当前健康的动态平衡
\end{enumerate}
