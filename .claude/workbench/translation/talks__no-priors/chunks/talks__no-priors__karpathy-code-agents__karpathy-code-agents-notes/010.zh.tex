\section{物理世界与机器人}

\subsection{自动驾驶的教训}

Karpathy 基于在 Tesla Autopilot 的经验，对机器人持谨慎态度：
\begin{itemize}
    \item 10 年前大量自动驾驶创业公司，大部分最终失败
    \item 物理世界需要巨大资本投入和长期信念
    \item 原子操作比 bit 操作慢百万倍
\end{itemize}

\subsection{Digital $\rightarrow$ Interface $\rightarrow$ Physical 路径}

\begin{knowledgebox}{三阶段发展路径}
Karpathy 预测 AI 影响将按以下顺序展开：
\begin{enumerate}
    \item \textbf{数字空间}（当前重点）：unhobbling existing digital information
    \item \textbf{数字-物理接口}：传感器和执行器——为 AI 提供物理世界的数据和操作能力
    \item \textbf{纯物理世界}：robotics, manufacturing 等——TAM 可能更大，但时间线更长
\end{enumerate}
类似 \textit{Daemon}（科幻小说）中描述的场景：AI 将人类作为其传感器和执行器。
\end{knowledgebox}

\subsection{本章小结}

物理世界的 AI 应用将滞后于数字空间，但最终 TAM 可能更大。数字-物理接口是近期的关键机会。
