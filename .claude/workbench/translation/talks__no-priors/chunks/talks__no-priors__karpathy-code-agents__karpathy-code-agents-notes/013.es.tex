\section{Síntesis y ampliación}

\subsection{Ideas centrales}

\begin{enumerate}
    \item \textbf{El paradigma de programación ya cambió}: desde diciembre de 2024, la forma de trabajar de los desarrolladores de vanguardia pasó de "escribir código" a "orquestar agentes". El cuello de botella se trasladó de la velocidad de tecleo al rendimiento de tokens y a la capacidad de orquestación de agentes
    \item \textbf{Everything is skill issue}: la capacidad de las herramientas actuales supera con mucho el aprovechamiento que la mayoría les da. El fallo casi nunca es que la herramienta no funcione, sino que se está usando de forma equivocada
    \item \textbf{Auto research ya es eficaz}: en dominios con métricas verificables, los ciclos de investigación automatizados ya muestran un potencial que supera a los investigadores humanos
    \item \textbf{Retirarse a sí mismo como cuello de botella}: maximizar el leverage significa minimizar la participación humana dentro del ciclo: "arrange it once and hit go"
    \item \textbf{Reestructuración agent-first}: la industria del software necesita pasar de una UI human-first a una API agent-first
    \item \textbf{El jaggedness del modelo es un rasgo fundamental}: el RL solo optimiza dominios verificables, y la conducta off-rails permanece estancada
    \item \textbf{El código abierto como contrapeso}: que el código cerrado lleve medio año de ventaja y el código abierto lo persiga de manera constante es el equilibrio dinámico saludable de hoy
\end{enumerate}
