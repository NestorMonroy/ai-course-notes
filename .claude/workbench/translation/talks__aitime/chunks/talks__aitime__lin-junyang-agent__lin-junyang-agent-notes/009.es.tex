\section{Síntesis y ampliación}

Esta presentación de Lin Junyang (林俊旸) mostró el panorama completo del equipo de Qwen en 2025, que puede resumirse en tres dimensiones:

\textbf{1. Evolución integral de las capacidades del modelo}
\begin{itemize}
    \item Texto: naturalización de Reasoning, 119 idiomas, contexto ultralargo
    \item Visión: VL sin pérdida de calidad, control de GUI, Reasoning visual
    \item Generación: generación de imágenes cercana a la realidad, gran mejora en la precisión de edición
    \item Voz: arquitectura de extremo a extremo Thinker-Talker
    \item Arquitectura: Qwen3-Next Hybrid Linear Attention
\end{itemize}

\textbf{2. El cambio de paradigma de Model a Agent}
\begin{itemize}
    \item El Coding Agent se entrena mediante RL interactivo con el entorno
    \item 67--69 puntos en SWE-Bench, con la capacidad integrada en un modelo unificado de gran tamaño
    \item El objetivo pasa de resolver problemas a tareas reales de ingeniería de software
\end{itemize}

\textbf{3. El ciclo virtuoso del ecosistema de código abierto}
\begin{itemize}
    \item El modelo pequeño (1.8B) surgió de la intención original de «permitir que los estudiantes de maestría puedan graduarse»
    \item El soporte multilingüe surgió de la retroalimentación de investigadores coreanos y usuarios paquistaníes
    \item La precisión de edición de imágenes surgió de un problema de desplazamiento que descubrió la comunidad de código abierto
    \item «Si la comunidad de código abierto no nos lo hubiera dicho, quizá nunca en la vida lo habríamos pensado»
\end{itemize}
