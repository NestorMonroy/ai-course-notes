\section{Ventaja de datos de las grandes empresas frente a las startups}

\begin{knowledgebox}{Diversidad de datos de una empresa de cien mil personas}
Una startup como Anthropic que genera datos para un coding agent necesita recurrir a proveedores de etiquetado de datos; estos proveedores tienen un alcance limitado, así que la diversity de los datos también queda limitada. Pero si se trata de una gran empresa de cien mil personas (como Tencent), esta cuenta por sí misma con escenarios de aplicación real abundantes, y puede capturar datos del mundo real más diverse, sin depender únicamente de proveedores de etiquetado o de Distillation.
\end{knowledgebox}
