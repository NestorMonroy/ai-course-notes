\section{引言}

Claude Cowork 被作者称为 2026 年最强大的生产力工具，但大多数人安装后只是试用了十分钟就回到了 ChatGPT。作者认为，问题的根源不在工具本身，而在于\textbf{初始配置（setup）}。

本文是 Corey Ganim 经过数月实践后整理的 Claude Cowork 完整入门包，涵盖四大插件、三类上下文文件和四套自动化工作流，目标是帮助用户从"觉得有趣"过渡到"改变工作方式"。

\begin{importantbox}{核心观点}
Cowork 的核心竞争力不在于对话能力，而在于\textbf{上下文系统（context system）}。正确的插件 + 上下文文件 + 工作流 = 真正的 AI 员工。作者的原话："The prompting game is over. The context game is everything."
\end{importantbox}
