\section{常见错误}
%% ============================================================

以下是官方总结的使用 Codex 时最常见的错误：

\begin{warningbox}{八大常见错误}
\begin{enumerate}[nosep]
    \item 在 prompt 中堆积持久性规则，而不是迁移到 \texttt{AGENTS.md} 或 skill
    \item 没有告诉 agent 如何运行 build 和 test 命令，导致它看不到自己工作的结果
    \item 在多步骤复杂任务中跳过规划
    \item 在理解工作流之前就给 Codex 完全的系统权限
    \item 在同一批文件上运行多个活跃线程，而不使用 git worktree
    \item 在工作流手动运行尚不可靠时就将其转为 automation
    \item 把 Codex 当成需要逐步看管的工具，而不是与自己并行工作的队友
    \item 使用一个线程管理整个项目而非每个任务一个线程，导致上下文膨胀
\end{enumerate}
\end{warningbox}

\subsection{本章小结}

避免上述八大常见错误，核心原则是：持久化规则写入 \texttt{AGENTS.md}、复杂任务先规划、权限先紧后松、并行而非看管、一任务一线程。
