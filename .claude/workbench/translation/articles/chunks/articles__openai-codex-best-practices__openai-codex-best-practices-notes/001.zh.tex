\section{引言}

OpenAI Codex 是一款 coding agent，支持 CLI、IDE 扩展和 Codex App 三种使用方式。本文档是 OpenAI 官方发布的 Codex 最佳实践指南，覆盖了从 prompting、规划、配置到 MCP 集成、Skills 封装和自动化调度的完整工作流。

\begin{importantbox}{核心理念}
不要把 Codex 当成一次性的助手，而应当视其为一个\textbf{需要持续配置和改进的队友}。核心路径：正确的任务上下文 $\rightarrow$ AGENTS.md 持久化指导 $\rightarrow$ 配置标准化 $\rightarrow$ MCP 外部集成 $\rightarrow$ Skills 封装 $\rightarrow$ Automations 自动化。
\end{importantbox}

\subsection{本章小结}

本文围绕六大主题展开：Prompt 编写、AGENTS.md 配置、系统配置、MCP 外部工具集成、Skills 技能封装、以及 Automations 自动化，旨在帮助用户从"能用"走向"好用"。
