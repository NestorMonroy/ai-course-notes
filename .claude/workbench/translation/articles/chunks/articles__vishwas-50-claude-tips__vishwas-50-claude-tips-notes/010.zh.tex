\section{总结与延伸}
%% ============================================================

这 50 条技巧覆盖了 Claude Code 使用的完整生命周期：

\begin{enumerate}
  \item \textbf{基础操作}：别名、快捷键、会话管理构成日常交互的骨架。
  \item \textbf{Prompt 工程}：匹配推理强度与任务复杂度，贴原始数据而非解释，让 Claude 采访你补全需求。
  \item \textbf{上下文控制}：频繁 \texttt{/clear}、引导 compaction、用 \texttt{/btw} 和 \texttt{/branch} 保持干净。
  \item \textbf{项目配置}：CLAUDE.md 精简且活、\texttt{.claude/rules/} 条件加载、\texttt{@imports} 按需引入。
  \item \textbf{安全与 Hooks}：CLAUDE.md 管建议，Hooks 管规则，关键逻辑必须人工审核。
  \item \textbf{质量保证}：反馈循环（测试+lint）、LSP 插件、对话式 PR review。
  \item \textbf{扩展能力}：Skills 按需加载、MCP Server 集成外部服务、CLI 优先。
  \item \textbf{并行工作}：Worktree、Subagent、Agent Teams、\texttt{claude -p} 各有适用场景。
\end{enumerate}

\begin{importantbox}{最核心的建议}
正如原文作者所说：你不需要全部 50 条。挑出上一次会话中最让你烦恼的那个问题，找到对应的技巧，明天就试用。一条真正落地的技巧，胜过五十条收藏夹里的书签。
\end{importantbox}
