\section{概述：Claude 架构师知识体系}

Claude Certified Architect 认证考试涵盖五大领域，考察候选人构建生产级 Claude 应用的综合能力。虽然考试仅对合作伙伴开放，但掌握这些知识本身就足以让你构建高质量的 AI 应用。

\begin{importantbox}{考试覆盖的四大核心技术}
\begin{enumerate}[leftmargin=1.5em]
    \item \textbf{Claude Code}：Anthropic 官方 CLI 工具，支持代码生成、CI/CD 集成
    \item \textbf{Claude Agent SDK}：用于构建 agentic 应用的开发套件
    \item \textbf{Claude API}：模型调用接口，含 tool\_use、Batches API 等
    \item \textbf{Model Context Protocol (MCP)}：工具与上下文集成的标准协议
\end{enumerate}
\end{importantbox}

考试要求候选人能够完成以下六类典型项目：

\begin{itemize}[leftmargin=1.5em]
    \item \textbf{客户支持解决 Agent}：Agent SDK + MCP + 升级机制（escalation）
    \item \textbf{Claude Code 代码生成}：CLAUDE.md 配置 + plan mode + slash commands
    \item \textbf{多 Agent 研究系统}：coordinator-subagent 编排模式
    \item \textbf{开发者生产力工具}：内置工具 + MCP servers
    \item \textbf{Claude Code CI/CD}：非交互式管道 + 结构化输出
    \item \textbf{结构化数据抽取}：JSON schemas + tool\_use + 验证循环
\end{itemize}

\subsection{本章小结}

Claude 架构师需要同时掌握 Claude Code、Agent SDK、API 和 MCP 四大技术栈。考试通过六类典型项目来检验综合能力，其中 Agentic Architecture 占比最高（27\%），是核心中的核心。
