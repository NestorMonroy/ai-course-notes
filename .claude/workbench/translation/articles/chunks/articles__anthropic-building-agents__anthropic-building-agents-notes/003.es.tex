\section{Componentes básicos: LLMs aumentados}

Antes de introducir los patrones de flujo de trabajo (Workflow) concretos, es necesario comprender los componentes básicos de un sistema agéntico: el \textbf{LLM aumentado}.

Un LLM aumentado es un módulo que superpone tres capacidades fundamentales sobre un LLM básico:

\begin{table}[H]
\centering
\begin{tabular}{>{\bfseries}l p{10cm}}
\toprule
Capacidad aumentada & Descripción \\
\midrule
Retrieval (búsqueda) & Obtener información relevante de bases de conocimiento externas, bases de datos o documentos, ampliando así el límite del conocimiento del modelo. \\
Tools (herramientas) & Invocar APIs externas, ejecutar código y manipular archivos, permitiendo al modelo interactuar con el mundo exterior. \\
Memory (memoria) & Mantener el contexto durante interacciones multironda, registrando y recuperando información previa. \\
\bottomrule
\end{tabular}
\caption{Tres capacidades fundamentales del LLM aumentado}
\end{table}

Los modelos actuales ya pueden \textbf{utilizar de manera proactiva} estas capacidades: generar consultas de búsqueda por su cuenta, seleccionar las herramientas adecuadas y decidir qué información conservar. Anthropic sugiere prestar atención a dos aspectos durante la implementación:

\begin{enumerate}
    \item \textbf{Personalizar} estas capacidades para casos de uso específicos, en lugar de buscar universalidad.
    \item Garantizar que estas capacidades ofrezcan una interfaz \textbf{concisa y completa con documentación} al LLM.
\end{enumerate}

\begin{knowledgebox}{Protocolo de contexto del modelo (MCP)}
El protocolo MCP, lanzado por Anthropic, permite a los desarrolladores acceder a un ecosistema creciente de herramientas de terceros mediante una implementación de cliente unificada. Esto significa que la capa de herramientas de un LLM aumentado puede estandarizarse y reutilizarse, evitando desarrollar cada proyecto desde cero. El MCP se está convirtiendo en infraestructura clave para el ecosistema de herramientas de agentes.
\end{knowledgebox}

\subsection{Resumen de la sección}
El LLM aumentado es un módulo fundamental para todos los sistemas agénticos, potenciado por Retrieval, Tools y Memory. Todos los patrones de flujo de trabajo (Workflow) y agentes subsiguientes asumen que cada llamada al LLM dispone de estas capacidades aumentadas.
