\section{数据导入与初步审查}

最快的起步方式是把文件路径贴给 Codex，让它做初步检查。此阶段需要回答的关键问题：

\begin{itemize}[nosep]
    \item 有哪些文件格式？
    \item 每个数据集大致代表什么？
    \item 哪些列可能是目标变量、标识符、日期、位置或度量？
    \item 明显的数据质量问题在哪里？
\end{itemize}

\begin{warningbox}{不要过早下结论}
此阶段只做\textbf{数据盘点}（inventory）和\textbf{解释说明}（explanation），不要急于得出分析结论。先理解数据的``长相''，再进入清洗和合并。
\end{warningbox}

\subsection{本章小结}
数据导入阶段的核心是``看清数据''而非``分析数据''。让 Codex 做好文件格式识别、字段解释和质量初筛。
