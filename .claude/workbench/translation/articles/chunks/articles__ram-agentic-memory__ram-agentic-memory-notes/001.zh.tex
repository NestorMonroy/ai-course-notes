\section{引言：为什么 Agent 需要记忆？}

大多数 LLM 的交互是\textbf{无状态的}——每一次新对话都是一张白纸。模型不知道你是谁、之前聊过什么、一起构建了什么。对于简单的聊天机器人，这无伤大雅；但对于一个需要执行任务、做出决策并随时间不断改进的 \textbf{Agent} 来说，这种"失忆症"是致命的。

\begin{importantbox}{记忆是 Agent 进化的关键}
真正的智能不仅仅是"回答得好"，而是能够\textbf{记住、学习并在已有经验上持续构建}。记忆将一个无状态的系统转变为一个能够真正进化的系统。
\end{importantbox}

\subsection{本章小结}

LLM 天生无状态，每次对话都从零开始。Agent 需要记忆系统来维持上下文、积累经验和持续学习。
