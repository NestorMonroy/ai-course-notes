\section{系列概述与课程导引}

本期是 Modern Agents 付费系列的第一期，从宏观视角串讲了整个系列未来将涉及的核心主题，并以 \textbf{Reasoning \& Planning} 作为切入点，对大语言模型（LLM）在规划领域的能力与不足进行了系统性的 survey。

\subsection{系列将覆盖的主题}

整个 Modern Agents 系列计划覆盖以下几大板块：

\begin{enumerate}
    \item \textbf{Reasoning and Planning}：语言模型的推理与规划能力，这是所有后续内容的基石。
    \item \textbf{经典 Workflow}：包括 Self-Critique（生成-评估-迭代循环）、Multi-Agent System（多智能体协作，核心在于 Separation of Concern）。
    \item \textbf{Context Engineering}：对语言模型相关技术的整体打包，重点关注 Memory 设计。
    \item \textbf{Self-Evolving}：以 AlphaEvolve、GPA 等为代表的自我进化技术。
    \item \textbf{框架实践}：LangChain / LangGraph 等框架的使用。
    \item \textbf{Graph-based 方法}：GraphRAG 等 Neuro-Symbolic 方案。
    \item \textbf{工具设计与封装}：为语言模型设计合适的 Tool / Server 以补足其短板。
    \item \textbf{Test-Time Computing}：并行思考（DeepConf）、Majority Voting 等推理时计算技术。
\end{enumerate}

\subsection{本章小结}

本系列的核心理念是：在不断的实践中掌握更多行之有效的 know-how，通过 Agent 的设计和开发来最大化语言模型的表现。
