\section{经典案例深度解析}

\subsection{Alpha Geometry：Neuro-Symbolic 方案}

\subsubsection{Alpha Geometry 第一代}

第一代 Alpha Geometry 的核心思路：
\begin{enumerate}
    \item 将原始几何问题翻译成\textbf{符号语言}
    \item 让\textbf{符号引擎}尝试直接求解
    \item 如果无法求解，交给\textbf{语言模型}提出构造（如添加辅助线）
    \item 符号引擎基于新构造推导出新的 facts
    \item 循环直到形成完整的解决方案
\end{enumerate}

例如：已知 $AB = AC$（等腰三角形），要证明两个角相等。仅凭 $AB = AC$ 符号引擎无法直接推导；但语言模型建议在 $BC$ 中点加一个 $D$ 点并连接 $AD$，就可以通过相似三角形、对角相等等性质完成证明。

\subsubsection{Alpha Geometry 第二代}

第二代引入了\textbf{多路并行搜索}：
\begin{itemize}
    \item 不止一个语言模型提 proposal，而是 multiple 的 neural model 并行搜索
    \item 各路搜索中间产生的新 facts 是\textbf{共享的}，可以形成新的前提（states），再交给不同 model 继续探索
    \item 这种并行思考策略启发了后续 Gemini Deep Think 版本的设计
\end{itemize}

\subsection{DeepConf：基于置信度的 Majority Voting}

DeepConf 的核心创新：
\begin{itemize}
    \item 引入 \textbf{Token Confidence} 概念
    \item 对每个 token 计算置信度，再 aggregate 得到整个 trace（完整解决方案）的置信度
    \item 基于置信度加权做 \textbf{Majority Voting}，而非简单的多数表决
\end{itemize}

\subsection{UCLA IMO 方案：Self-Critique Workflow}

\begin{importantbox}{Generate-Verify-Correct 循环}
UCLA 求解 IMO 的方案是一个典型的 Self-Critique workflow：
\begin{enumerate}
    \item Step 1-2：产生一个初始 proposal（solution）
    \item Step 3：交给 Critique 做 verification，给出具体的问题和意见
    \item Step 4：语言模型基于反馈做 correction
    \item 循环执行，直到连续 5 次通过验证（接受）或连续 10 次失败（拒绝）
\end{enumerate}
其关键词是 \textbf{capable}——模型本身有能力解决问题，只是需要合适的 workflow 来激发。
\end{importantbox}

\subsection{本章小结}

三个经典案例分别展示了 Neuro-Symbolic（Alpha Geometry）、Test-Time Scaling（DeepConf）和 Self-Critique（UCLA IMO）三种 Planning 策略，它们殊途同归——通过精心设计的 workflow 来最大化模型的推理潜力。
