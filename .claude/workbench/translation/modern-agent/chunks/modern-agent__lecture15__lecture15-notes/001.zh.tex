\section{引言：为什么需要上下文压缩？}

在使用 Codex 等 Coding Agent 进行长时间开发时，对话的上下文会不断累积。当上下文长度逼近模型的 Context Window 上限时，如果不加处理，Agent 将无法继续接收新信息。\textbf{上下文压缩}（Compact）正是为了解决这一问题而设计的机制——在保留关键信息的前提下，将冗长的对话历史压缩为精炼的摘要，使 Agent 能够"无缝衔接"后续工作。

本期主要参考了 Twitter 上一篇知名帖子对 Codex Compact 机制的逆向分析，结合 Codex 源码进行解读。
