\section{Compact 的基本原理}

\subsection{触发方式}

Compact 可以通过两种方式触发：

\begin{itemize}
    \item \textbf{手动触发}：用户主动执行压缩命令。
    \item \textbf{自动触发}：当上下文长度达到 Context Window 的 \textbf{90\%} 时，系统自动执行一次压缩。
\end{itemize}

\subsection{先压缩，后交接}

无论哪种触发方式，Compact 的流程都是一致的：

\begin{importantbox}{两步走：Compact + Handoff}
\begin{enumerate}
    \item \textbf{压缩（Compact）}：将当前全部对话历史压缩为一份精炼的"交接摘要"。
    \item \textbf{交接（Handoff）}：将压缩后的摘要注入到新的对话上下文中，使"接手"的 LM 能够继续工作。
\end{enumerate}
\end{importantbox}

\subsection{本章小结}

Compact 的本质是一个"上下文检查点"（Context Checkpoint），在不丢失关键信息的前提下为 Agent 腾出 Context Window 空间。
