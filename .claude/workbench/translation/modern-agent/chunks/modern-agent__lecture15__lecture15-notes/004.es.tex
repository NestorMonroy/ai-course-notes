\section{Contenido del Compact Prompt y el Handoff Prompt}

\subsection{Prompt de compresión (Compact Prompt)}

En el código fuente de Codex, para los proveedores distintos de OpenAI se ofrece un prompt de compresión en texto plano (\texttt{compact.prompt.md}), cuya instrucción central es la siguiente:

\begin{importantbox}{Contenido íntegro del Compact Prompt}
«Estás ejecutando una compresión de un punto de control de contexto. Crea un resumen de traspaso para otro LM que retomará esta tarea, el cual debe incluir:
\begin{itemize}
    \item El progreso actual
    \item Las decisiones clave que ya se tomaron
    \item El contexto, las restricciones y las preferencias del usuario que sean importantes
    \item El trabajo que aún no se ha completado
    \item Cualquier dato, ejemplo o material clave necesario para continuar el trabajo
\end{itemize}
Sé conciso, estructurado y enfócate en ayudar al siguiente LM a continuar el trabajo sin interrupciones.»
\end{importantbox}

\subsection{Prompt de traspaso (Handoff Prompt / Summary Prefix)}

El traspaso ocurre después de completarse la compresión; el contenido de \texttt{summary.prefix.md} es el siguiente:

\begin{importantbox}{Contenido íntegro del Handoff Prompt}
«Otro modelo de lenguaje ya comenzó a resolver este problema y generó un resumen de su proceso de razonamiento. También tienes acceso al estado de las herramientas que ese modelo de lenguaje utilizó. Usa esta información para continuar el trabajo ya realizado, sin repetir esfuerzos. A continuación está el resumen de ese modelo de lenguaje: usa la información del resumen para apoyar tu propio análisis.»
\end{importantbox}

\subsection{El proceso completo de dos pasos}

\begin{enumerate}
    \item \textbf{Paso 1 — Compresión}:
    \begin{itemize}
        \item Entrada: System Prompt + Compact Prompt + todo el historial de la conversación.
        \item Salida: un «texto cifrado» estructurado (el resumen comprimido).
    \end{itemize}
    \item \textbf{Paso 2 — Traspaso}:
    \begin{itemize}
        \item Entrada: System Prompt + Handoff Prompt + el resumen comprimido + la nueva solicitud del usuario.
        \item Salida: una respuesta normal del agente, que continúa el trabajo sin interrupciones.
    \end{itemize}
\end{enumerate}

\subsection{Resumen de la sección}

El Compact Prompt guía al modelo para que genere un «resumen de traspaso», y el Handoff Prompt guía al modelo que lo recibe para que use ese resumen y continúe el trabajo. Juntos, ambos conforman el ciclo cerrado de «comprimir $\rightarrow$ traspasar $\rightarrow$ continuar».
