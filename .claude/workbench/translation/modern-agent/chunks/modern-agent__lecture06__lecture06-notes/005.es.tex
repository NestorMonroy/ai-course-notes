\section{Síntesis y ampliación}

\begin{enumerate}
    \item \textbf{La salida estructurada y la invocación de herramientas son infraestructura del desarrollo de Agents}: implementan, a nivel de la API, el contrato de interfaz entre módulos.
    \item \textbf{Entender la solicitud HTTP subyacente} ayuda a depurar: response\_format y tools son dos campos distintos.
    \item \textbf{LangChain ofrece un encapsulamiento de nivel más alto}: serialización/deserialización automáticas, pero por debajo sigue siendo la API de OpenAI.
    \item \textbf{La salida estructurada puede implementar CoT}: estructurar el proceso de razonamiento es una técnica práctica para mejorar el rendimiento.
    \item \textbf{La capacidad de salida estructurada de los LLM modernos ya es muy sólida}: puede prescindirse de una gran cantidad de convenciones de formato del prompt hechas a mano y de análisis manual de la salida.
\end{enumerate}
