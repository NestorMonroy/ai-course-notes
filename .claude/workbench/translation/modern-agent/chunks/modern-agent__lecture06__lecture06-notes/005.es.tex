\section{Síntesis y ampliación}

\begin{enumerate}
    \item \textbf{La salida estructurada y la llamada a herramientas son la infraestructura del desarrollo de Agentes}: implementan, a nivel de la API, el acuerdo de interfaz entre módulos.
    \item \textbf{Entender la solicitud HTTP subyacente} ayuda a depurar: response\_format y tools son dos campos distintos.
    \item \textbf{LangChain ofrece una encapsulación de más alto nivel}: serialización/deserialización automática, pero por debajo sigue siendo la API de OpenAI.
    \item \textbf{La salida estructurada permite implementar CoT}: estructurar el proceso de pensamiento es una técnica práctica para mejorar el rendimiento.
    \item \textbf{La capacidad de salida estructurada de los LLM modernos ya es muy sólida}: se puede omitir una gran cantidad de convenciones de formato de Prompt manuales y de análisis de la salida.
\end{enumerate}
