\section{Encapsulamiento a nivel de LangChain}

\subsection{with\_structured\_output}

El método \texttt{with\_structured\_output} de LangChain simplifica aún más el uso:

\begin{itemize}
    \item Se pasa directamente un modelo de Pydantic
    \item Internamente se convierte de manera automática a JSON Schema y se coloca en response\_format
    \item El resultado devuelto ya es un objeto instanciado (un paso más de deserialización automática que con la API de OpenAI)
\end{itemize}

\begin{warningbox}{Diferencia entre las dos rutas}
\begin{itemize}
    \item \texttt{with\_structured\_output} $\rightarrow$ pasa por \texttt{response\_format} (el JSON Schema se alinea con la semántica de los campos)
    \item \texttt{bind\_tools} $\rightarrow$ pasa por \texttt{tools} (semántica de Function Calling)
\end{itemize}
En esencia, un modelo de Pydantic también es una especie de función (instanciar la clase $\approx$ llamar al constructor), por lo que bind\_tools de LangChain también puede aceptar un modelo de Pydantic.
\end{warningbox}

\subsection{Resumen de la sección}

LangChain agrega un nivel adicional de encapsulamiento sobre la API de OpenAI: serialización automática y deserialización automática, lo que hace la experiencia de uso más sencilla.
