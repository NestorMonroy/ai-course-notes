\section{Encapsulamiento en el nivel de LangChain}

\subsection{with\_structured\_output}

El método \texttt{with\_structured\_output} de LangChain simplifica aún más el uso:

\begin{itemize}
    \item Se pasa directamente un Pydantic Model
    \item Internamente se convierte de manera automática a JSON Schema y se coloca en response\_format
    \item El resultado devuelto es directamente un objeto instanciado (un paso más que la API de OpenAI: la deserialización automática)
\end{itemize}

\begin{warningbox}{Diferencia entre las dos rutas}
\begin{itemize}
    \item \texttt{with\_structured\_output} $\rightarrow$ usa \texttt{response\_format} (el JSON Schema se alinea con la semántica de los campos)
    \item \texttt{bind\_tools} $\rightarrow$ usa \texttt{tools} (semántica de Function Calling)
\end{itemize}
En esencia, un Pydantic Model también es una especie de Function (instanciar una clase equivale aproximadamente a llamar al constructor), por lo que el bind\_tools de LangChain también puede aceptar un Pydantic Model.
\end{warningbox}

\subsection{Resumen de la sección}

LangChain hace un encapsulamiento adicional sobre la base de la API de OpenAI: serialización automática, deserialización automática, con lo que la experiencia de uso resulta más sencilla.
