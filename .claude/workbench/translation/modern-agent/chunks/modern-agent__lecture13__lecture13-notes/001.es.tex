\section{Definición y características de los Modern AI Agents}

\subsection{Qué es un Modern AI Agent}

Herramientas como Codex, Claude Code, Gemini CLI y OpenAI Codex pertenecen a la categoría de Modern AI Agent. En comparación con los marcos de Agent anteriores, presentan tres características distintivas:

\begin{importantbox}{Las tres características de los Modern AI Agent}
\begin{enumerate}
    \item \textbf{Modelos base más potentes}: usan como base modelos de vanguardia como GPT-4.5 y Opus 4.6, con una capacidad sólida de razonamiento y generación de código
    \item \textbf{Capacidades agénticas de múltiples turnos y mayor alcance}: después de que el usuario emite una Query, el Agent puede sostener interacciones largas de múltiples turnos, invocando herramientas por cuenta propia, leyendo y escribiendo archivos, y ejecutando comandos hasta completar tareas complejas
    \item \textbf{Un Agent Runtime cuidadosamente diseñado}: gran cantidad de inyección de prompts (agents.md, src.md, memory.md), Tools integradas abundantes, un sistema de Skills, diseño de Spawn Agent / Multi-Agent, y un sistema completo de programación y orquestación
\end{enumerate}
\end{importantbox}

\subsection{El lugar central de Context Engineering}

\begin{importantbox}{La esencia de todos los Modern AI Agent}
En esencia, todos los Modern AI Agent hacen lo mismo: \textbf{Context Engineering}. Mantienen una lista de mensajes (Message List) y, mediante un diseño cuidadoso del contenido, la posición y el momento de carga de los mensajes, construyen el contexto completo que necesita la inferencia del modelo grande, ya sea remoto o local.

Principio clave: ya se trate de Skills o de herramientas MCP, si no se exponen en el Context (la Message List de la API), el modelo \textbf{no puede} percibir la existencia de esas Skills y Tools, y por lo tanto no tiene forma de invocarlas.
\end{importantbox}

\subsection{Resumen de la sección}

El núcleo de un Modern AI Agent es Context Engineering: mantener y administrar el contexto a lo largo de la ejecución del Agent Loop, lo que incluye la inyección previa de instrucciones, la exposición de Skills, el registro de Tools y la gestión del historial de la conversación.
