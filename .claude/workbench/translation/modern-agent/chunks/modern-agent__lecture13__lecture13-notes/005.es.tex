\section{Síntesis y ampliación}

\subsection{Panorama general del Context Engineering}

En esta entrega se completó el análisis integral del Context Engineering de Codex:

\begin{itemize}
    \item \textbf{Skills}: aparecen en el contenido del User Message, con carga progresiva
    \item \textbf{Tools}: aparecen en el campo tools de la API, incluyendo Tools integradas y Tools dinámicas de MCP
    \item \textbf{Instrucciones de sistema}: campo instructions independiente
    \item \textbf{Historial de mensajes}: registro de la interacción de varios turnos, que puede comprimirse mediante compact
    \item \textbf{Memory}: sistema de memoria persistente
\end{itemize}

\begin{importantbox}{Tres ideas clave}
\begin{enumerate}
    \item Ya sean Skills, MCP o Tools preestablecidas, si no se exponen en el Context, el modelo no puede percibirlas ni invocarlas
    \item Skills y Tools son técnicamente ortogonales e independientes: Skills está en el contenido del mensaje, Tools en el campo de herramientas
    \item El trabajo central de todo Modern Agent es el Context Engineering: administrar con cuidado el contexto que se le entrega al modelo
\end{enumerate}
\end{importantbox}
