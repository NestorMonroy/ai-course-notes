\section{如何编写好的 Skills}

讲者总结了编写高质量 Skills 的要素：

\begin{enumerate}
    \item \textbf{足够抽象}：Skills 必须是通用的（Common）、有原则的（Principled）、可复用的。
    \item \textbf{形式化描述}：使用非常 Formal 的、逻辑性的描述语言（如 Dot 语言流程图）。
    \item \textbf{专家经验沉淀}：一定是资深软件开发人员的实践凝练。
    \item \textbf{Writing 能力}：需要良好的技术写作能力，但可以借助语言模型辅助润色。
\end{enumerate}

\subsection{本章小结}

好的 Skill 是"专家经验 + 形式化表达"的结晶，既要有深度的工程理解，又要有让模型易于执行的结构化描述。
