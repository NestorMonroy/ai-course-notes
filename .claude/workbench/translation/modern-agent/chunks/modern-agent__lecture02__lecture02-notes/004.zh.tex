\section{LangSmith 监控平台}

\subsection{配置与使用}

LangSmith 是一个在线监控平台，用于追踪和调试 Agent 的工作流程。配置方式：
\begin{enumerate}
    \item 在 \texttt{.env} 中配置 LangSmith API Key
    \item 开启 tracing 功能（设置为 true）
    \item 设置 project 名称
\end{enumerate}

\subsection{核心调试方法}

\begin{importantbox}{Debug 的核心 Tips}
通过检查模型的\textbf{输入输出}来理解其工作流程。重点关注每一次语言模型调用（橙色部分）的输入和输出——搞清楚输入输出，就搞清楚了整个工作流程。所有前续步骤都是为了构建这样一个消息列表。
\end{importantbox}

\subsection{本章小结}
LangSmith 提供了可视化的 Agent 调试能力，核心方法是通过监控 LLM 调用的输入输出来理解整个工作流程。
