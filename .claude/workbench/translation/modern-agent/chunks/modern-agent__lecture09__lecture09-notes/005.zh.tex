\section{检索模式详解：Naive、Hybrid、Mixed}

\subsection{三种检索模式}

LightRAG 支持三种检索模式（Query Mode），各有适用场景：

\begin{importantbox}{三种检索模式对比}
\begin{itemize}
    \item \textbf{Naive}：仅基于 Vector 检索——对 Query 做 Embedding，与 Chunk Embedding 计算 Cosine Similarity，返回 TopK
    \item \textbf{Hybrid}：纯粹基于知识图谱——结合 Local Search（实体邻域）和 Global Search（关系匹配），不直接查向量库中的原始文本块
    \item \textbf{Mixed}：Hybrid + Naive——既有 KG 的全局推理，又有传统向量检索获取原始文本块
\end{itemize}
\end{importantbox}

\subsection{关键词提取：Low-Level 与 High-Level}

LightRAG 的检索首先从用户 Query 中提取两类关键词：

\begin{itemize}
    \item \textbf{Low-Level 关键词}：具体的实体名称（如人名、产品名），用于 Local Search
    \item \textbf{High-Level 关键词}：宏观主题、抽象概念，用于 Global Search
\end{itemize}

这一步同样由语言模型完成，可通过 LangFuse 的 Trace 监控其输入输出。

\subsection{Local Search（局部搜索）}

\begin{enumerate}
    \item 使用 Low-Level 关键词在实体向量库中做 Vector Search
    \item 检索到对应的实体节点
    \item 在 Graph 中做一跳遍历（Traverse），获取直接关联的邻居实体
    \item 返回一跳范围内的实体和关系信息作为 Context
\end{enumerate}

Local Search 以实体为中心，适合回答关于特定实体的详细问题。

\subsection{Global Search（全局搜索）}

\begin{enumerate}
    \item 使用 High-Level 关键词在关系向量库中做 Vector Search
    \item 检索到对应的关系（边）
    \item 返回这些关系及其关联的实体作为 Context
\end{enumerate}

Global Search 以关系为中心，关注宏观主题，适合回答跨领域、跨文档的综合性问题。

\subsection{本章小结}

LightRAG 通过 Low-Level/High-Level 关键词分离和 Local/Global 双重搜索，实现了从具体实体到宏观主题的多层次检索。Mixed 模式则在此基础上补充原始文本块，提供最全面的信息覆盖。
