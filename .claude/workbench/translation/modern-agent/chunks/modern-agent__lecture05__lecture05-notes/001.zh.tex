\section{工作背景与核心发现}

\subsection{令人振奋的结果}

本期介绍了一篇对作者启发极大的工作：\textbf{原生 Gemini 2.5 Pro}（非 DeepMind 官方 tune 过的版本）通过精心设计的 Agent Workflow，求解了 IMO 2025 六道题中的前五道，达到人类金牌水平。

\begin{importantbox}{核心发现}
关键词是 \textbf{capable}——模型本身有能力解决这些极其困难的数学问题，此前表现不佳是因为没有通过合适的 Workflow 来最大化激发模型的潜力。这对 Agent 设计的启示是巨大的。
\end{importantbox}

\subsection{本章小结}

这一工作证明了 Agent Workflow 设计的重要性：同样的模型，不同的 Workflow 可以带来质的飞跃。
