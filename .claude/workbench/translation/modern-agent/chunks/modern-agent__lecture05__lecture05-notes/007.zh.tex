\section{总结与延伸}

\begin{enumerate}
    \item \textbf{Generate-Verify-Correct 循环}是一个强大且通用的 Workflow 模式，本文在 IMO 问题上的成功验证了其有效性。
    \item \textbf{初始解质量决定成败}：如果初始解方向正确（与标准解有较大 overlap），后续循环大概率能修正细节；如果方向错误，则难以纠正。
    \item \textbf{Prompt 设计是 Workflow 的灵魂}：结构化的输出格式为自动化的分支判断和数据流转提供了基础。
    \item \textbf{角色分离}：Generator 只管生成，Verifier 只管验证，Corrector 只管修正——各司其职是 Multi-Agent 设计的核心原则。
    \item \textbf{Agent 设计的价值}：同样的模型（Gemini 2.5 Pro），通过 Workflow 设计可以从"做不出"变为"金牌水平"。
\end{enumerate}
