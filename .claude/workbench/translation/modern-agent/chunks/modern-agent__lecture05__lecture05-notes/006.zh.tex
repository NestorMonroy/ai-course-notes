\section{Gemini API 使用注意事项}

\begin{knowledgebox}{技术细节}
\begin{itemize}
    \item Gemini API 的角色是 system / user / model（而非 system / user / assistant）
    \item Thinking 输出是 summarize 后的结果，不是原生的 thinking 过程
    \item Thinking Budget 设置为 32768 tokens，但实际有时会达到 34000+（控制不严格）
    \item 由于 Thinking 过程很长（数万 token），使用 HTTP Request 容易超时，建议使用 SDK + Streaming
\end{itemize}
\end{knowledgebox}
