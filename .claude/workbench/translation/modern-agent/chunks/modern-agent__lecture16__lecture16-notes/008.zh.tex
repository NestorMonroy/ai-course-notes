\section{总结与延伸}

本期从 Tool Design 的角度深入拆解了 Codex 的 12 个预定义工具，核心要点回顾：

\begin{enumerate}
    \item \textbf{三层架构}：内部规格（Tool Spec）$\rightarrow$ Wire Layer（网络传输）$\rightarrow$ Handlers（本地执行）。
    \item \textbf{Apply Patch}：用 Lark Grammar 约束的 Diff DSL，将代码编辑结构化、可审计化。
    \item \textbf{Execute Commands + Write Stdin}：覆盖一次性执行和交互式会话两种场景。
    \item \textbf{Subagent 系统}：通过 Spawn / Send Inputs / Wait / Close / Resume 五个原语管理子 Agent 生命周期，实现上下文隔离与并发执行。
    \item \textbf{View Image}：多模态 Agent 的图像桥接工具，将"看图"显式化为 Function Call。
    \item \textbf{Function Call Output 的回填}：模型对工具返回值的感知完全依赖 Runtime 将结果注入上下文，而非 Tool 定义中的 output\_schema。
\end{enumerate}

理解了这 12 个 Tool 的设计，加上前几期对 Context Engineering 的分析，就能对各种 Coding Agent 的内部运作形成深入直观的认知。核心启示是：\textbf{Agent 的能力边界 = 底层模型能力 + Agent Runtime 维护的工具与上下文 + Harness 层的流程约束}。
