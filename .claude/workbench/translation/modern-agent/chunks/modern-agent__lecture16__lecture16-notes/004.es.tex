\section{Execute Commands y Write Stdin}

\subsection{Execute Commands}

Execute Commands es una llamada de comando de una sola vez: se inicia el proceso, se ejecuta un fragmento y se obtiene la salida. También es compatible con «ejecutar código generado por el modelo»: el modelo puede generar primero un fragmento de código y luego ejecutarlo mediante Execute Commands.

\begin{knowledgebox}{«Patch is All You Need»}
El expositor citó una frase popular en la industria: una vez que se convierte una aplicación en algo interactuable por línea de comandos, todas las operaciones pueden realizarse con dos primitivas: Patch (editar) y Command (ejecutar).
\end{knowledgebox}

\subsection{Write Stdin}

Write Stdin se usa para enviar entradas de manera continua a un programa que \textbf{ya está en ejecución}, es decir, para dialogar con una CLI interactiva (como iPython, Node REPL, MySQL, GDB, etc.), enviando entradas y obteniendo salidas incrementales.

\begin{importantbox}{Execute Commands frente a Write Stdin}
\begin{itemize}
    \item \textbf{Execute Commands}: llamada de una sola vez. Inicia $\rightarrow$ ejecuta $\rightarrow$ obtiene la salida $\rightarrow$ termina.
    \item \textbf{Write Stdin}: interacción continua. Envía nuevas instrucciones a un proceso ya en ejecución y obtiene respuestas incrementales.
\end{itemize}
\end{importantbox}

\subsection{Resumen de la sección}

Execute Commands cubre la gran mayoría de las necesidades de «ejecutar cierto código o comando», mientras que Write Stdin complementa el escenario de las sesiones interactivas; juntos constituyen la base de la capacidad de ejecución del agente.
