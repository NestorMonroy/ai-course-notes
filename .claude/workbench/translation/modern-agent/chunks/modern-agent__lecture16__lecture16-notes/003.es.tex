\section{Apply Patch: edición estructurada de código}

\subsection{¿Por qué no reescribir el archivo directamente?}

Apply Patch es la herramienta de edición de código más central en Codex. Su idea de diseño es: \textbf{no dejar que el modelo reescriba libremente todo el archivo, sino que produzca un diff estructurado}: qué líneas se agregaron, qué líneas se eliminaron, qué archivos se agregaron, qué archivos se eliminaron.

\begin{importantbox}{Patch DSL: un lenguaje específico de dominio restringido}
Apply Patch define un DSL (Domain Specific Language) basado en la gramática de Lark:
\begin{itemize}
    \item Se envuelve con \texttt{*** begin patch} / \texttt{*** end patch}.
    \item Las operaciones se marcan con \texttt{*** update file} / \texttt{*** add file} / \texttt{*** delete file}.
    \item Obliga al modelo a expresar la intención de edición en forma de diff, en lugar de modificar el texto libremente.
\end{itemize}
\end{importantbox}

\subsection{¿Por qué el modelo puede entender la gramática de Lark?}

\begin{enumerate}
    \item En el cuerpo de la solicitud, Codex envía al modelo el texto de la gramática de Lark como parte de la descripción de la herramienta.
    \item La primera System Instruction también incluye las instrucciones de uso de Apply Patch.
    \item La instrucción exige explícitamente: \textbf{la edición de un solo archivo debe hacerse con Apply Patch, sin usar Python para leer y escribir archivos}; cuando un comando de Shell sencillo o Apply Patch basta, no se debe buscar otro camino.
\end{enumerate}

\subsection{El flujo de ejecución del Patch}

Al recibir el contenido del Patch, el handler no modifica el archivo de inmediato, sino que:
\begin{enumerate}
    \item \textbf{Valida la sintaxis}: comprueba si el Patch cumple con la gramática de Lark.
    \item \textbf{Deduce el alcance del impacto}: determina qué archivos se modifican y qué permisos de lectura y escritura se requieren.
    \item \textbf{Aprobación de permisos}: si hay requisitos de aprobación adicionales, primero obtiene el permiso.
    \item \textbf{Ejecuta el Patch}: aplica el diff al sistema de archivos.
\end{enumerate}

\subsection{Resumen de la sección}

Apply Patch restringe la operación de alto riesgo que es "modificar código" a un DSL de diff estructurado, lo cual ahorra contexto (no es necesario producir el archivo completo) y hace que cada edición sea auditable y verificable.
