\section{View Image：多模态 Agent 的桥接工具}

\subsection{为什么需要单独的 Tool？}

GPT 是多模态模型，理论上可以直接处理 Base64 编码的图片。但在 Agent 系统中，需要一个专门的 Tool 来实现：

\begin{knowledgebox}{Agent 自主决定"看什么图"}
View Image 的意义在于：\textbf{Agent 需要自主决定何时查看哪张图片}。模型通过调用 View Image Tool，告诉 Runtime "我现在需要看这张图"，Runtime 负责读取文件、编码为 Base64、作为 Function Call Output 注入上下文。

这一步（Prepare Image Input）必须由 Runtime 完成，而非预先塞入所有图片。
\end{knowledgebox}

\subsection{工作流程}

\begin{enumerate}
    \item 用户提供一个图片的绝对路径（如"请读取这张照片：/path/to/image.jpg"）。
    \item 模型产生 Function Call：\texttt{view\_image(file\_path="/path/to/image.jpg")}。
    \item Runtime 读取文件、转换为 Base64。
    \item 以 Image Content 形式注入到后续的 \texttt{response.create} 输入中。
    \item 模型基于视觉理解继续推理。
\end{enumerate}

\subsection{去重优化}

Tool Description 中包含一条规则：\textbf{如果这张图片在历史上已经看过，则不需要再次读取}——可以直接复用之前上下文中的视觉信息。

\subsection{本章小结}

View Image 是本地图像与多模态模型之间的桥接工具，将"看图"这一操作显式化为 Function Call，使 Agent 能够按需获取视觉信息。
