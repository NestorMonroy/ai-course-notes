\section{总结与延伸}

\begin{enumerate}
    \item \textbf{快速上手 Agent 项目的路径}：概念 $\rightarrow$ Prompt $\rightarrow$ 监控工具（LangFuse）。
    \item \textbf{LightRAG 是一个基于知识图谱的 RAG 方案}，相比纯向量 RAG 具有更强的语义理解和增量更新能力。
    \item \textbf{双层检索}（Low-Level + High-Level）复用了 GraphRAG 中 Local 和 Global 检索的思想，但实现更轻量。
    \item \textbf{LangFuse 是理解 Agent 内部机制的利器}：通过 trace 所有 API 调用，可以清晰看到每个环节的输入输出。
    \item \textbf{核心 API}：\texttt{ainsert}（增量索引）和 \texttt{aquery}（检索回答）——对应 Indexing 和 Retrieval 两大流程。
\end{enumerate}
