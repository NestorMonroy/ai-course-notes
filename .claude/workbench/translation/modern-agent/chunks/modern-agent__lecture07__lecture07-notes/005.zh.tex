\section{LightRAG 本地存储结构}

运行 LightRAG 后，在工作目录下会生成以下文件：

\begin{itemize}
    \item \texttt{graph.graphml}：XML 格式的知识图谱（实体 + 关系）
    \item \texttt{kv\_store\_*}：键值存储（Chunk、Entity、Relation 的 K-V 对）
    \item \texttt{vdb\_*}：向量数据库（默认使用 Nano Vector DB）
    \begin{itemize}
        \item \texttt{vdb\_chunks}：Chunk 的 Embedding
        \item \texttt{vdb\_entities}：Entity 的 Embedding
        \item \texttt{vdb\_relationships}：Relation 的 Embedding
    \end{itemize}
\end{itemize}

检索时的数据流：关键词 $\rightarrow$ Embedding Search（VDB） $\rightarrow$ 图遍历（GraphML） $\rightarrow$ 补充原始文档（KV Store） $\rightarrow$ 组装 Context $\rightarrow$ LLM 生成回答。
