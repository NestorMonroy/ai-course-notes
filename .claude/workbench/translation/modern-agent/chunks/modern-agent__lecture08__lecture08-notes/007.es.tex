\section{Síntesis y ampliación}

Esta clase completó la transición completa de las herramientas tradicionales de visión por computadora a los agentes multimodales modernos:

\begin{enumerate}
    \item \textbf{SAM3} eleva, mediante la introducción de un prompt de texto, la «segmentación de todo» a la «detección, segmentación y reconocimiento de todo»
    \item \textbf{SAM3 Agent} muestra cómo usar un VLM como cerebro de razonamiento y SAM3 como ejecutor visual, para lograr Visual Grounding mediante llamadas a herramientas
    \item \textbf{Gemini 2.5 Flash} representa la dirección de la multimodalidad nativa de extremo a extremo, que unifica la detección, la segmentación y el reconocimiento en un solo modelo conversacional
\end{enumerate}

\begin{knowledgebox}{Reflexión adicional}
\begin{itemize}
    \item \textbf{Embodied AI}: la segmentación visual es la base de la manipulación robótica: identificar objetos, entender la escena y planear el agarre
    \item \textbf{El futuro del Visual Prompting}: a medida que mejore la capacidad de los modelos, las pistas visuales que aporta el humano pasarán de una «anotación explícita» a un «bosquejo visual generado de forma autónoma por el modelo» (como la Agentic Vision de Gemini)
    \item \textbf{Segmentación de vocabulario abierto}: la combinación de SAM3 y un VLM logra la Open-Vocabulary Segmentation, ya no limitada a una lista predefinida de categorías
\end{itemize}
\end{knowledgebox}
