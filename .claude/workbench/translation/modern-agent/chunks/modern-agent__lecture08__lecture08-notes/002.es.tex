\section{Visual Prompting: el nuevo paradigma del prompting visual}

\subsection{Qué es Visual Prompting}

La idea central de Visual Prompting es: \textbf{en lugar de decirle a la IA con palabras qué buscar, se anota directamente en la imagen}. Las señales visuales concretas (Visual Cues) incluyen:

\begin{itemize}
    \item \textbf{Anotación de punto} (Point Prompt): se especifica un punto en la imagen
    \item \textbf{Anotación de caja} (Bounding Box Prompt): se dibuja un recuadro
    \item \textbf{Anotación de garabato} (Scribble): se dibuja libremente sobre una región
    \item \textbf{Anotación de texto}: se escribe una explicación de texto en la imagen
\end{itemize}

Estas señales visuales guían al modelo para realizar tareas visuales específicas, como VQA, segmentación de imágenes, detección de objetos, etc. En el campo de la generación de imágenes, el usuario también puede seleccionar con un recuadro una región de la imagen y escribir un texto, para guiar al modelo de generación visual a hacer ediciones más precisas.

\begin{importantbox}{La esencia de Visual Prompting}
Visual Prompting es una forma de interacción que codifica directamente en la imagen la intención visual humana. Compensa la insuficiencia del prompt puramente textual en la localización espacial: para ciertas tareas visuales (como «ese objeto azul que está más a la izquierda»), describirlas con palabras resulta a la vez extenso y propenso a la ambigüedad, mientras que anotar directamente sobre la imagen es directo y claro.
\end{importantbox}

\subsection{Visual Prompting y Visual Grounding}

Visual Grounding es el proceso inverso de Visual Prompting:
\begin{itemize}
    \item \textbf{Visual Prompting}: la persona anota en la imagen $\rightarrow$ guía al modelo para que entienda
    \item \textbf{Visual Grounding}: el modelo entiende el texto $\rightarrow$ localiza en la imagen (enmarca o segmenta el objetivo)
\end{itemize}

La combinación de ambos forma un ciclo completo de «diálogo visual».

\subsection{Resumen de la sección}

Visual Prompting extiende el prompting textual tradicional a la dimensión visual, y ofrece a las tareas de visión por computadora una forma de interacción humano-máquina más natural y más precisa. Es un concepto básico para entender la colaboración entre SAM3 y los VLM.
