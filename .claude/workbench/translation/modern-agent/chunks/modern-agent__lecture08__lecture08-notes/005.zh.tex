\section{Gemini 2.5 Flash：原生多模态视觉能力}

\subsection{对话式的检测分割识别}

Gemini 2.5 Flash 代表了一种更"端到端"的路线：无需外挂 SAM3 等专业模型，模型本身就具备检测、分割和识别的能力。

\begin{importantbox}{Gemini 2.5 Flash 的原生视觉能力}
截至 2025 年 12 月，支持原生 Mask 分割输出的 VLM 仅有 Gemini 2.5 Flash。其关键特点：
\begin{itemize}
    \item 对话式交互：用自然语言 Query 触发分割
    \item 输出格式：List of Dict，每个 Dict 包含 \texttt{box\_2d}（边界框）、\texttt{mask}（分割掩码图片）、\texttt{label}（描述性标签）
    \item BBox 坐标在 1000×1000 范围内归一化，叠加到原图时需要转换
\end{itemize}
\end{importantbox}

\subsection{使用方式}

调用 Gemini 2.5 Flash 进行分割的关键配置：

\begin{itemize}
    \item 使用 \texttt{gemini-2.5-flash} 模型
    \item 设置 \texttt{temperature=0}（确保确定性输出）
    \item 传入图文 Prompt，使用官方推荐的分割 Prompt 模板
\end{itemize}

\subsection{分割效果评估}

以多个孩子跑步的测试图为例：
\begin{itemize}
    \item 六个孩子中，五个的检测分割非常准确
    \item 第三个孩子的框略有偏差
    \item 整体准确率很高，Mask 质量是 0/1 矩阵的像素级分割
\end{itemize}

\begin{knowledgebox}{Gemini 2.5 Flash Preview 与 Pro 的区别}
\begin{itemize}
    \item \textbf{Gemini 2.5 Flash}：支持完整的 Mask 输出，是目前唯一支持原生对话式分割的 VLM
    \item \textbf{Gemini 2.5 Flash Preview}（新发布）：暂不支持 Mask 输出
    \item \textbf{Gemini 2.5 Flash 3 Pro}：可能只输出描点而非完整 Mask
\end{itemize}
\end{knowledgebox}

\subsection{本章小结}

Gemini 2.5 Flash 展示了 VLM 发展的一个重要方向——将检测、分割、识别能力原生内化到一个统一模型中，实现真正的"对话式视觉理解"。虽然 SAM3 + VLM 的组合方案更灵活，但端到端方案代表了未来的趋势。
