\section{引言：Agentic Vision 的启发意义}

本期介绍 Google 最新发布的 Gemini 2.5 Flash Agentic Vision 功能。这项工作将视觉推理与代码执行相结合，让模型能够主动"调查"图像——而非被动地"看一眼就猜"。

\begin{knowledgebox}{Modern Agents 与 Agentic RL Training 的关系}
讲者将两个系列做了明确定位：
\begin{itemize}
    \item \textbf{Modern Agents}：侧重推理、多轮工具调用、Novel Prompting 技巧
    \item \textbf{Agentic RL Training}：侧重算法、系统架构、Post-Training
\end{itemize}
Agentic Vision 恰好连接了两者——它展示的多轮推理效果，启发了如何通过 Post-Training 来强化和激励模型的基础能力。
\end{knowledgebox}
