\section{典型应用场景分析}

\subsection{场景一：精确计数（手指/踏板）}

\textbf{任务}：数一幅图中有多少根手指/踏板。

\textbf{Agentic Vision 的做法}：
\begin{enumerate}
    \item 模型识别出所有目标，生成每个目标的 BBox 坐标（原生能力）
    \item 写代码在图上画出编号标注框，形成视觉草图
    \item 基于标注后的图，确认数量
\end{enumerate}

\begin{warningbox}{关于"Tricky"的讨论}
讲者指出这个示例有些"tricky"——模型在输出 BBox 时其实已经知道了目标数量（BBox 数 = 手指数）。标注和二次确认更多是一种"视觉验证"而非真正的推理突破。
\end{warningbox}

\subsection{场景二：高密度表格解析 + 计算}

\textbf{任务}：解析图中的表格数据，进行归一化计算并可视化。

\textbf{传统模型的问题}：VLM 在多步视觉算术中经常出现幻觉（hallucination），尤其是浮点数运算。

\textbf{Agentic Vision 的解决方案}：
\begin{enumerate}
    \item 使用原生图表理解能力提取表格数据
    \item \textbf{将计算"下载"到确定性的 Python 环境}——在代码中完成归一化等数学运算
    \item 在 Python 中完成 Matplotlib 可视化
\end{enumerate}

\begin{importantbox}{计算卸载（Computation Offloading）}
Agentic Vision 的一个重要设计模式是\textbf{将精确计算从模型推理中卸载到代码执行环境}。模型负责理解和规划，Python 负责精确计算。这有效规避了 LLM 固有的数值计算不稳定性。
\end{importantbox}

\subsection{场景三：物品分类与标注}

\textbf{任务}：将图中的不同物品分类，用不同颜色的箭头标注到对应的容器中。

这是一个综合性任务，需要模型同时具备：
\begin{itemize}
    \item 物体识别（知道这是什么）
    \item 分类推理（应该放到哪个类别）
    \item 视觉标注（画箭头连接物品和容器）
\end{itemize}

讲者测试发现，模型在分类逻辑上仍有瑕疵（如将某些物品错误分类），但整体的视觉交互能力令人印象深刻。

\subsection{场景四：动物生命周期图表}

\textbf{任务}：从图中裁切出所有动物，以它们的图片作为 icon，在 Matplotlib 图表中按生命周期长度排序展示。

这个案例涉及\textbf{非常多轮的工具调用}——裁切、排序、绘图等步骤需要多次 Think-Act-Observe 循环。最终生成的图表兼具信息性和美观性。

\subsection{本章小结}

Agentic Vision 的应用场景涵盖了精确计数、表格解析、物品分类、图表生成等多种任务。其核心模式是"模型负责理解与规划 + 代码负责精确执行"。
