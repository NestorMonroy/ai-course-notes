\section{总结与延伸}

Gemini Agentic Vision 是一项将模型基础视觉能力与 Agentic 多轮推理结合的创新工作。它的核心贡献不仅在于功能本身，更在于揭示了一条清晰的技术路线：

\begin{enumerate}
    \item \textbf{模型层}：预训练获得基础视觉能力（检测、分割、识别）+ Open World Knowledge
    \item \textbf{工具层}：封装通用的 Code Execution Tool
    \item \textbf{行为层}：通过 Post-Training 激励 ReAct 式的多轮工具调用
    \item \textbf{应用层}：模型自主生成 Visual Scratchpad，基于视觉证据做推理
\end{enumerate}
