\section{FreeGrasp: Visual Prompting en la sujeción robótica}

\subsection{Planteamiento del problema}

FreeGrasp resuelve el problema de la sujeción robótica de forma libre (free-form grasping): el usuario da una instrucción de sujeción ambigua en lenguaje natural (por ejemplo, «sujeta el coche de juguete rojo que está abajo»), y el robot debe entender la instrucción, ubicar el objeto objetivo, manejar las oclusiones y, finalmente, completar la sujeción.

\begin{knowledgebox}{El manejo de oclusiones es el reto clave}
En escenarios reales de sujeción, el objeto objetivo suele estar ocluido por otros objetos. FreeGrasp diseñó un pipeline completo para manejar las oclusiones: primero identificar el objetivo → determinar si está ocluido → retirar el objeto que lo ocluye → volver a sujetar el objetivo. Este proceso requiere que el VLM tenga capacidad de razonamiento en varios pasos.
\end{knowledgebox}

\subsection{Diseño del pipeline}

El flujo de procesamiento de FreeGrasp:

\begin{enumerate}
    \item \textbf{Entrada}: imagen RGBD (el RGB para el razonamiento visual, el Depth para la ejecución del brazo robótico) + instrucción en lenguaje natural
    \item \textbf{Detección de la imagen completa}: se usa un modelo de CV preentrenado para detectar todos los objetos de la imagen completa y obtener el punto central de cada objeto
    \item \textbf{Visual Marking}: se marca un número en la posición de cada punto central
    \item \textbf{Razonamiento del VLM}: usando un Prompt estructurado, se hace que el VLM razone en varios pasos a partir de la imagen numerada:
    \begin{itemize}
        \item identificar el objeto objetivo (¿qué número es el objetivo?)
        \item determinar si está ocluido (¿qué objetos ocluyen al objetivo?)
        \item planear el orden para retirar los objetos que lo ocluyen
    \end{itemize}
    \item \textbf{Segmentación y sujeción}: se segmenta el objeto objetivo, un algoritmo tradicional estima la postura de sujeción y el brazo robótico la ejecuta
\end{enumerate}

\begin{importantbox}{El significado de Free-form}
El «Free» de FreeGrasp se refiere al grado de libertad de la entrada del usuario: se puede describir el objetivo de la sujeción con cualquier lenguaje natural, sin necesidad de un formato de instrucción estructurado. Esto se debe a la potente capacidad de comprensión del lenguaje natural del VLM.
\end{importantbox}

\subsection{Resumen de la sección}

FreeGrasp aplica la técnica de Visual Prompting al campo de la sujeción robótica: mediante el pipeline de detección → numeración → razonamiento del VLM → segmentación → ejecución, logra la sujeción de objetos a partir de instrucciones en lenguaje natural de forma libre, y la detección y el manejo de oclusiones son la innovación central.
