\section{Grounding DINO 与检测-分割 Pipeline}

\subsection{Grounding DINO：开放词汇目标检测}

Grounding DINO 是一个开放词汇（open-vocabulary）的目标检测模型，能根据自然语言描述在图片中定位目标物体，输出边界框（bounding box）。

\begin{importantbox}{检测→分割的标准 Pipeline}
在实际应用中，通常将检测与分割组合使用：
\begin{enumerate}
    \item 用 Grounding DINO 根据文本描述检测目标，得到边界框
    \item 计算边界框的中心点
    \item 将边界框或中心点作为 Prompt 输入给 SAM，对目标物体做像素级分割
\end{enumerate}
这样就从粗粒度的框定位，精细化为像素级的不规则多边形分割区域。
\end{importantbox}

以自动驾驶场景为例：用户描述"红色跑车"，Grounding DINO 先在图中框出红色跑车的边界框，然后 SAM 基于这个框做精确的像素级分割，得到不规则多边形区域。

\subsection{Grounding SAM 2：视频级物体追踪}

Grounding SAM 2 将 Grounding DINO 与 SAM 2 的视频追踪能力相结合，用于视频级别的物体追踪（tracking）：

\begin{enumerate}
    \item \textbf{选取关键帧}：从视频中取出一个典型帧
    \item \textbf{检测目标}：用 Grounding DINO 检测目标物体（如"little girl"），得到边界框
    \item \textbf{初始分割}：将边界框作为 Box Prompt 输入 SAM 2，分割出目标
    \item \textbf{视频追踪}：用 SAM 2 的 Tracking 模块，在整个视频的所有帧中持续追踪并分割该目标
\end{enumerate}

追踪阶段可以使用多种提示信息：
\begin{itemize}
    \item 原始的边界框
    \item 分割区域中采样的点（Point Prompt）
    \item 分割得到的 Mask 区域
\end{itemize}

\subsection{本章小结}

Grounding DINO 提供开放词汇检测能力，与 SAM 系列结合形成检测→分割的标准 Pipeline。Grounding SAM 2 进一步将其扩展到视频追踪场景，实现单帧检测+全视频追踪的端到端流程。
