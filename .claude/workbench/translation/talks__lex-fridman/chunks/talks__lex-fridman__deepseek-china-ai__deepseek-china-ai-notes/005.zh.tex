\section{基础设施与算力竞赛}

\subsection{超大规模集群}

AI 基础设施正在经历人类历史上前所未有的扩张速度。对比历史：GPT-4 用了 20,000 张 A100（$\sim$15-20 MW），相当于一个标准数据中心。仅仅两年后，单个集群规模已经扩大了 10 倍。

数据中心用电从美国电力的 2-3\% 将增长到 2028-2030 年的 10\%+。下一代 Blackwell GPU 功耗达 1200W（vs 当前 Hopper 700W），明年目标是 500,000-700,000 GPU 集群。Elon 的目标是 100 万张 GPU——\textit{``我从不怀疑 Elon。''} (Dylan)

\begin{knowledgebox}{训练的功率尖峰问题}
训练创造尖峰式电力需求：GPU 计算时高功率 $\to$ 交换权重时 GPU 空闲、低功率。这种脉冲式负载对电网非常不友好。

Meta 意外开源了一个 PyTorch 算子：\texttt{PowerPlant.no\_blowup = 1}——让 GPU 在空闲期计算无意义的数字来平滑功率曲线。\textit{``你很容易就能把设备烧了。''} (Dylan)

Elon 的解决方案更优雅：Tesla Mega Pack 电池组吸收功率瞬变。
\end{knowledgebox}

\subsubsection{液冷革命}

空气冷却曾是标准方案，但 Blackwell 的 1200W 热密度使其不可行。Google TPU 已采用水冷多年。Elon 在 Memphis 率先大规模 GPU 液冷——90 个集装箱大小的水冷机组环绕设施外围。下一代 NVIDIA 强制要求水冷。

液冷的连带好处：芯片能更紧密排列 $\to$ 更短的物理距离 $\to$ 更高速的互连。这对训练效率至关重要。

\subsection{Stargate 项目详解}

OpenAI + Oracle 在德克萨斯州 Abilene 的项目：满载功率 2.2 GW——超过大多数城市的用电量。

\begin{importantbox}{Stargate 的规模与资金}
\begin{itemize}
    \item Phase 1 总拥有成本约 \$100B（\$50B 实际投入 + \$50B 运营成本）
    \item 第一期：$\sim$\$5-6B 服务器 + \$1B 数据中心（Oracle 已在建设）
    \item 资金来源：SoftBank（可能 \$25B）、Oracle、MGX（阿联酋，\$1.5T AI 基金但``墨迹未干''）
    \item OpenAI 自身承诺 \$19B 但只有 \$6B 现金 + \$4B 债务
\end{itemize}

Elon 说得对：\textit{``钱不存在。''} 但 Dylan 相信钱最终会来。Trump 的角色是去监管化（联邦土地数据中心、简化审批），而非提供资金。\textit{``Trump 是一个 hype man……减少监管让他们能更快建设。''} (Dylan)
\end{importantbox}

\subsection{电力、冷却与物理约束}

训练创造尖峰式电力需求：GPU 计算时高功率，交换权重时 GPU 空闲、低功率。Meta 意外开源了一个 PyTorch 算子：\texttt{PowerPlant.no\_blowup = 1}——让 GPU 在空闲期计算假数字以平滑功率。

Elon 的解决方案：Tesla Mega Pack 电池组吸收功率瞬变。液冷革命：Google TPU 已采用水冷，Elon 在 Memphis 率先大规模 GPU 液冷（90 个集装箱大小的水冷机组）。下一代 NVIDIA Blackwell 强制要求水冷。液冷使芯片能更紧密排列，实现更高速互连。

\subsection{GPU 走私与扩散规则}

\begin{warningbox}{GPU 走私已成现实}
字节跳动是最大的``走私者''——从 Oracle、Google、各小型云商全球租用 500,000+ GPU。物理走私也存在：有人在旧金山机场头等舱带着 SuperMicro GPU 箱子飞上海。

2024 年估计有 200-300K GPU 通过新加坡、马来西亚的小公司流入中国。新的 AI 扩散规则限制中国关联实体租用 $<$2000 GPU 或购买 $<$1500 GPU。

\textit{``GPU 将超越毒品和武器成为每公斤最高价值的走私品。''} (Dylan)
\end{warningbox}

\subsection{Google TPU 与 NVIDIA 垄断}

Google TPU 内部很优秀（为搜索、YouTube、Gemini 优化），但软件栈未公开发布。这是一个组织问题而非技术问题：Google Cloud、TPU 团队、DeepMind 和搜索团队彼此独立运作，没有统一的对外策略。NVIDIA 的整个文化是服务外部客户；Google 服务内部客户。

一个具体的例子揭示了这种内部优化的弊端：Gemma 模型的词表大小为 TPU 优化（TPU 有大型矩阵乘法单元），但在 GPU 上运行效率很低。当 Google 的研究者离开去创业时，他们才发现外部基础设施有多难——\textit{``研究者离开 Google，创办公司，发现基础设施很难，然后回去了。''} (Dylan)

AMD 的情况：硬件尚可但软件（ROCm）糟糕到令人发指。\textit{``我们在给 AMD 提交最多的 bug——为什么是我们 SemiAnalysis 在提交最多的 bug？''} (Nathan) 一个半导体分析公司在给芯片厂商报告软件 bug，这说明了 AMD 的软件生态有多薄弱。

Intel 处境更艰难：失去制程领先地位、没有 AI 芯片胜利、CEO 被解雇、PC 和服务器市场份额持续流失。Samsung 的制造良率也在下降。

最极端的情景：世界可能最终只剩 TSMC 一家在做尖端芯片研发。这意味着一个岛屿——位于中国大陆几百公里外的岛屿——承载着全球科技的命运。

\subsection{本章小结}

AI 基础设施正在经历前所未有的扩张——Stargate 级项目代表 \$100B 规模投资。电力、冷却和 GPU 走私是新的物理约束。NVIDIA 垄断短期内无法撼动——AMD 软件太差，Intel 在衰落，Google TPU 不对外。
