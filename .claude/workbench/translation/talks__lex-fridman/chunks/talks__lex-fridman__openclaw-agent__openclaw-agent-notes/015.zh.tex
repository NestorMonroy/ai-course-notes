\subsection{如何把片段索引用于团队协作}

建议把这张索引表直接纳入团队 wiki，并对每个片段补三类链接：实现代码、测试样例、故障案例。这样复盘时不再依赖个人记忆，而是依赖可检索证据。

\begin{importantbox}{团队落地建议：三联追踪法}
每次需求评审时，要求给出：
\begin{itemize}
    \item \textbf{观点链接}：对应访谈片段或内部原则；
    \item \textbf{实现链接}：对应代码 PR 或配置变更；
    \item \textbf{验证链接}：对应测试报告或线上观测。
\end{itemize}
若三联缺任一项，说明需求尚未形成可治理闭环。
\end{importantbox}

\subsection{本章小结}
长访谈的价值不在“金句收藏”，而在可回放、可追踪、可执行。时间片段索引是把认知资产沉淀为工程资产的低成本方法。
