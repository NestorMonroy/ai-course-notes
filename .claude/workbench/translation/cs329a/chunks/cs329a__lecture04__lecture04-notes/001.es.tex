\section{Una perspectiva unificada: ¿de dónde viene la retroalimentación?}

Un sistema de automejora necesita una señal que le indique al modelo "qué tan bien lo acaba de hacer". Esta clase compara tres tipos de retroalimentación:

\begin{enumerate}
    \item \textbf{observación de herramienta (tool observation)}: resultados de búsqueda, contenido de páginas web o el estado del entorno;
    \item \textbf{retroalimentación de ejecución (execution feedback)}: errores de compilación, pruebas unitarias, comportamiento en tiempo de ejecución;
    \item \textbf{AI feedback}: el modelo critica, revisa y compara respuestas con base en principios escritos por humanos.
\end{enumerate}

\videofigure{figures/thought-action-feedback.jpg}{El pensamiento guía la acción, la acción produce retroalimentación, y la retroalimentación corrige de nuevo al pensamiento.}{00:01:32--00:03:32}

Los tres tipos de métodos corresponden respectivamente a ReAct, RLEF y Constitutional AI. Comparten el mismo ciclo cerrado:

$$
\text{state}\rightarrow\text{reason / act}\rightarrow\text{feedback}
\rightarrow\text{revision or update}.
$$

\begin{importantbox}{La retroalimentación puede modificar solo la trayectoria actual, o bien los parámetros del modelo}
ReAct principalmente lee la observation en tiempo de inferencia y ajusta el siguiente paso; RLEF toma el resultado de la ejecución como reward de RL para actualizar el modelo de código; Constitutional AI primero usa los datos de critique--revision para SFT, y después usa la AI preference para RL. Distinguir estos dos niveles evita confundir "poder reintentar" con "ya haber aprendido".
\end{importantbox}

\subsection{Cuatro dimensiones para evaluar la calidad de la retroalimentación}

\begin{itemize}
    \item \textbf{Autenticidad}: si proviene de un entorno real y no del modelo hablando consigo mismo;
    \item \textbf{Granularidad}: si solo indica el éxito o fracaso final, o si señala errores concretos;
    \item \textbf{Costo}: si requiere expertos humanos, ejecución en sandbox o un modelo grande adicional;
    \item \textbf{Escalabilidad}: si puede generar automáticamente una gran cantidad de ejemplos de entrenamiento.
\end{itemize}

\subsection{Resumen de la sección}

La retroalimentación es la interfaz entre el modelo y el objetivo. Las herramientas y el código proporcionan señales externas observables, mientras que el AI feedback proporciona una señal normativa escalable pero más subjetiva; la confiabilidad del sistema depende de si estas señales corresponden realmente al objetivo final.
