\section{DAPO：让长链 Reasoning RL 稳定扩展}

\subsection{Naive GRPO 的四类问题}

\videofigure{figures/dapo-problems.jpg}{Naive GRPO 在长 reasoning 上出现熵坍塌、无效样本、长度偏差和不稳定。}{00:53:34--00:54:24}

DAPO（Decoupled Clip and Dynamic sAmpling Policy Optimization）通过一组相互配合的技术，把 AIME 表现逐步从 naive baseline 推高。

\subsection{Clip-Higher：允许优质低概率动作更快上升}

标准 PPO 对概率上升和下降使用对称 clipping。对长 CoT，正确但稀有的 token/action 初始概率很低，过紧的上界会阻止它们快速增长。Clip-Higher 使用更宽的上升 clipping 区间：

$$
\operatorname{clip}(\rho,1-\epsilon_{\rm low},1+\epsilon_{\rm high}),
\qquad \epsilon_{\rm high}>\epsilon_{\rm low}.
$$

\videofigure{figures/clip-higher.jpg}{Asymmetric Clip-Higher 保留更多对优质稀有行为的正向更新。}{00:54:24--00:55:46}

这有助于维持探索，但上界过宽也可能导致 policy 突然偏向少数轨迹，因此仍需监控 KL 与 entropy。

\subsection{Dynamic Sampling：只训练有对比信号的问题}

对每题采样 64 个回答。若 64 个全对或全错，组内 advantage 都接近零。Dynamic sampling 丢弃这类组，补采“部分正确、部分错误”的题目。

\videofigure{figures/dynamic-sampling.jpg}{Dynamic sampling 过滤全对与全错组，保留有效梯度。}{00:55:46--00:57:46}

\begin{knowledgebox}{Dynamic sampling 是在线 curriculum}
题目只有在当前 policy 既会成功又会失败时最有学习价值。随着模型能力变化，这个“学习边界”会移动，采样器自动把训练计算集中到当前适中难度样本。
\end{knowledgebox}

\subsection{Token-Level Loss：修正长度权重}

Sample-level loss 让每个回答贡献相同权重；长回答的每个 token 因此被平均稀释。Token-level loss 按所有 token 聚合，使长 reasoning 的局部决策得到更直接的梯度。

\videofigure{figures/token-loss.jpg}{Token-level objective 避免长回答的每个 token 被过度降权。}{00:57:46--00:58:48}

\begin{warningbox}{Token-level weighting 也可能偏爱长答案}
若 reward 只看终局，长轨迹拥有更多被更新 token，可能诱导模型无意义延长 reasoning。必须与长度成本、停止策略和 overlong punishment 配合。
\end{warningbox}

\subsection{Soft Overlong Punishment}

硬截断把刚超过最大长度的高质量推理与严重超长回答同样判罚，产生高方差噪声。Soft punishment 在接近长度上限时逐步增加惩罚，让模型平滑学习收束。

\videofigure{figures/overlong.jpg}{Soft overlong punishment 避免最大长度硬边界带来的噪声。}{00:58:48--00:59:42}

\subsection{渐进式收益}

\videofigure{figures/dapo-results.jpg}{Clip-Higher、soft overlong、token loss 与 dynamic sampling 逐项提升 AIME。}{00:59:42--01:00:42}

课程总结的趋势是：naive GRPO 约 30，加入 overlong filtering、asymmetric clipping、soft punishment、token-level loss 与 dynamic sampling 后逐步提升到 40+ 区间。重点不是单个数字，而是每项技术修复一个具体训练病理。

\subsection{Scaling RL 应监控什么}

\videofigure{figures/rl-monitoring.jpg}{长 reasoning RL 需监控响应长度、entropy、reward 分布与有效样本率。}{01:00:42--01:02:26}

仅看 training loss 容易误判。至少应监控：

\begin{itemize}
    \item 响应长度是否增长后稳定，而非无限膨胀；
    \item token entropy 是否快速坍塌；
    \item 全对/全错组比例与有效 batch 比例；
    \item KL、clip fraction 与梯度范数；
    \item pass@1、majority@$k$、pass@$k$ 的不同变化；
    \item reward 与独立真实评估是否仍一致。
\end{itemize}

\subsection{本章小结}

DAPO 的贡献是把 reasoning RL 视为完整系统：clip 控制探索，dynamic sampling 保证梯度，token loss 修正长度权重，soft punishment 平滑约束输出。Scaling RL 的成败由这些机制共同决定。
