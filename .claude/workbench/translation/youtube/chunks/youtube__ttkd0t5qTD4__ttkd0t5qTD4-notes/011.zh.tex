\section{总结与延伸}

\subsection{ speaker closing：从英雄到系统}

访谈的最后，姚顺宇谈到自己没有太多 AI 行业内的偶像，因为他进入这个行业时，个人英雄主义时代已经过去。他承认早期 AI 和物理中都有英雄人物，例如 Hinton 或 Transformer 团队，但今天的前沿 AI 更像集体主义工程。一个人可以发起方向、推动产品、修正路线，但真正的模型进步需要数据、算力、训练系统、评估、产品和组织共同配合。

\subsection{本笔记的核心提炼}

\begin{enumerate}
\item 模型能力没有简单停滞，预训练是否到头不能只看公开 benchmark。
\item 前沿模型差异正在从“能力高低”转向“行为定义、数据构造和产品体验”。
\item Coding 爆发的关键不是代码补全，而是长程 agent 工作流。
\item 蒸馏的价值取决于训练信号设计；硬蒸只是低级复制。
\item Anthropic 的启示是 top-down 技术组织与产品化协同；Gemini 的启示是大规模横向资源和 long-horizon 方向。
\item 未来研究员需要会用 AI，但更要理解 AI 产物、检查细节并承担责任。
\item AI 的下一个蓝海未必是语言模型主线，而可能在机器人、多模态、科学 AI、长程任务和新产品交互中。
\end{enumerate}

\subsection{拓展阅读}

\begin{itemize}
\item OpenAI scaling laws 与 Chinchilla scaling laws：理解“预训练是否到头”的两类历史背景。
\item SWE-bench 与 agentic coding 评估：理解 coding benchmark 为什么会接近饱和但产品体验仍有差异。
\item Transformer、seq2seq、scaling law、tool use agent 相关论文：理解访谈中提到的影响 AI 进程的关键技术脉络。
\end{itemize}

\begin{importantbox}{最后的判断}
这期访谈最值得带走的一句话，不是“AI 不需要脑子”，而是“AI 需要靠谱、细致和负责”。当模型能力越来越强，实现变得更容易，真正的稀缺能力会转向定义问题、验证系统、组织协作和承担结果。
\end{importantbox}
