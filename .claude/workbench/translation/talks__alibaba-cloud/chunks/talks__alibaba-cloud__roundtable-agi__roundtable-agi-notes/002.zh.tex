\section{数量与质量的双重加速}

\subsection{从一家独大到群雄并起}

蒋大昕从数量和质量两个维度总结过去18个月的进展：

\begin{knowledgebox}{数量维度}
每个月都有新模型、新产品涌现：OpenAI的Sora（2月）、GPT-4O（5月）、O1（9月）；Anthropic的Claude 3到3.5系列；Google的Gemini系列；Meta的Llama系列等。从GPT-4一家独大，到群雄并起、你追我赶。
\end{knowledgebox}

\begin{importantbox}{质量维度：三大标志性突破}
\begin{enumerate}
\item \textbf{GPT-4O}：多模态融合的新台阶——将视觉理解（GPT-4V）、视觉生成（DALL-E/Sora）、声音模型（Whisper/Voice Engine）统一在一起。物理世界本身就是多模态的，融合是必然方向。
\item \textbf{特斯拉FSD V12}：端到端大模型，从感知信号直接生成控制序列。自动驾驶是从数字世界走向物理世界的标志性场景。
\item \textbf{O1}：第一次证明语言模型也可以有人脑的慢思考（System 2）能力，这是归纳世界的基础前提。
\end{enumerate}
\end{importantbox}

\subsection{纵向与横向的双重扩展}

杨植麟从两个维度分析：

\begin{itemize}
\item \textbf{纵向（智商）}：竞赛数学从完全不及格到90多分；代码能力击败专业编程选手；上下文长度从4--8K跃升至128K甚至百万级
\item \textbf{横向（技能）}：多模态理解与生成、论文转podcast、视频生成等模态间转化日益成熟
\end{itemize}

\begin{knowledgebox}{Learning Curve在变陡}
朱军补充了一个重要观察：各个领域的learning curve正在变得更陡。例如视频生成从Sora震惊世界到行业追平仅用了半年。核心原因是大家对技术路线的认知和准备已经到位，加上云基础设施的成熟。
\end{knowledgebox}

\subsection{本章小结}

过去18个月，AGI在数量（模型密度）和质量（标志性突破）上均显著加速。纵向智商持续攀升，横向技能快速扩展，且各领域的追赶速度越来越快。
