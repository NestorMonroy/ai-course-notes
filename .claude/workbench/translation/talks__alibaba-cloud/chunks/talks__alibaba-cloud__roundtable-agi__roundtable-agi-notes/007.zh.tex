\section{总结与延伸}

本次圆桌讨论在O1刚发布的背景下展开，三位嘉宾从不同维度（创业视角、学术视角、技术视角）对AGI的现状和未来做出了判断。核心共识如下：

\begin{enumerate}
\item \textbf{加速而非减速}：过去18个月AGI发展在加速，数量和质量双重提升
\item \textbf{O1是范式变革}：开辟RL Scaling新维度，赋予模型System 2能力，推动AGI从L1迈向L2
\item \textbf{泛化是核心挑战}：从Narrow到General需要解决reward定义和过程监督数据问题
\item \textbf{算力需求将爆发}：推理端确定增长，训练端大概率增长，参数量可能重新启动Scaling
\item \textbf{创业机会扩大}：有确定方向（RL Scaling）但不确定路径，利好创新型团队
\item \textbf{三阶段路线}：模拟世界、探索世界、归纳世界——过去18个月在每个阶段都有标志性突破
\end{enumerate}
