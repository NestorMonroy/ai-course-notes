\section{Web 应用开发的演进}

\subsection{传统 Web 技术栈}

现代 SaaS 开发以 Web 应用为中心已有超过二十年。传统的技术栈经历了多代演进：

\begin{itemize}
    \item \textbf{LAMP}：Linux + Apache + MySQL + PHP
    \item \textbf{MERN}：MongoDB + Express + React + Node.js
    \item \textbf{JAM}：JavaScript + APIs + Markup
    \item \textbf{Serverless}：无服务器架构
\end{itemize}

无论哪种技术栈，架构都遵循经典的三层模式：客户端（client-side）$\rightarrow$ 服务端（server-side）$\rightarrow$ 数据库（database）。

\subsection{第一代低代码/无代码}

\begin{itemize}
    \item Wix、Squarespace、Webflow 等可视化建站工具
    \item 降低了建站门槛，但定制能力有限
\end{itemize}

\subsection{AI 时代的应用构建}

\begin{importantbox}{从写代码到说需求}
AI 应用构建工具的核心转变：从``写代码构建应用''到``用自然语言描述需求，AI 生成应用''。这比第一代 no-code 平台更加用户友好，同时保留了更强的定制能力。
\end{importantbox}

新一代 AI 应用构建工具：
\begin{itemize}
    \item \textbf{Lovable}：AI 驱动的全栈应用生成
    \item \textbf{Replit}：在线 IDE + AI 编程
    \item \textbf{Vercel v0}：自然语言 $\rightarrow$ React UI 组件
    \item \textbf{Base44}：低代码 + AI
    \item \textbf{Cursor / Claude Code}：通用 AI 编码工具也可用于应用构建
\end{itemize}

\begin{knowledgebox}{工程师角色的转变}
AI 应用构建工具正在使工程师变得更加\textbf{跨职能}（cross-functional）：开发者现在也承担了设计（design）和产品管理（product management）的职责。同时，非技术人员也可以构建应用——``Anyone can build an app now.''
\end{knowledgebox}

\subsection{本章小结}

Web 应用开发从 LAMP 到 Serverless，再到 AI 应用构建，每一代都降低了门槛、提高了效率。AI 时代的核心转变是：自然语言成为``编程语言''。
