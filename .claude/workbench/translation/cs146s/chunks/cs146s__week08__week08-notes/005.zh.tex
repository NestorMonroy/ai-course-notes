\section{总结与延伸}

Week 8 展示了 AI 如何变革应用构建：从传统 LAMP 栈到 AI 驱动的自然语言 $\rightarrow$ 应用的范式。v0 的架构详解揭示了 App Builder 的``魔法''背后是精心设计的 workflow 和 composite model。

\subsection{关键要点}

\begin{itemize}
    \item Web 开发从 LAMP $\rightarrow$ MERN $\rightarrow$ JAM $\rightarrow$ Serverless $\rightarrow$ AI App Builder 演进
    \item AI 使工程师更加跨职能，非技术人员也可以构建应用
    \item v0 架构：Intent $\rightarrow$ Context $\rightarrow$ Code Gen $\rightarrow$ Validation $\rightarrow$ Human Review
    \item ``Agent 是 Workflow''——核心不是单一模型调用，而是多步流水线
    \item Stream manipulation 和 composite model family 解决通用模型的局限
    \item 最大局限：出错时仍需人类理解底层代码来调试
\end{itemize}

\subsection{给团队的执行清单}

\begin{enumerate}
    \item 先选一个低风险内部工具或原型项目试点，而不是直接上核心业务页面
    \item 提前定义设计系统和组件边界，让生成结果能稳定落到已有工程规范中
    \item 把 AI 生成结果纳入正常 code review、测试和回退流程，而不是作为例外流程处理
\end{enumerate}
