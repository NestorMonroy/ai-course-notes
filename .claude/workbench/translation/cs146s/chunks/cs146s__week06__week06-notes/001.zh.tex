\section{软件安全的基础知识}

\subsection{为什么安全比以往更重要}

软件错误可以摧毁用户信任并带来巨大的财务损失。当 LLM 编写了你的大部分代码时，你需要\textbf{更加}广泛的防护栏来防止这些错误。

\begin{importantbox}{AI 编码时代的安全悖论}
AI 编码工具提高了代码产出速度，但同时也增加了引入安全漏洞的风险。代码审查的人类工程师成为最后的安全防线——审查一段你没亲手写的代码比审查自己写的代码更具挑战性。
\end{importantbox}

\subsection{传统威胁图景}

常见的软件安全威胁包括：
\begin{itemize}
    \item \textbf{SQL Injection}：通过恶意 SQL 输入操纵数据库
    \item \textbf{Cross-Site Scripting (XSS)}：在网页中注入恶意脚本
    \item \textbf{Broken Authentication}：认证机制的缺陷
    \item \textbf{Insecure Direct Object References (IDOR)}：直接对象引用未经授权检查
    \item \textbf{Security Misconfigurations}：安全配置错误
    \item \textbf{Sensitive Data Exposure}：敏感数据泄露
\end{itemize}

\subsection{本章小结}

传统安全威胁在 AI 编码时代并未消失，反而因代码产出速度的提升而更加需要系统性的防护机制。
