\section{课程回顾：AI 软件开发的全景图}

\subsection{十周课程的知识地图}

在展望未来之前，让我们回顾这门课所覆盖的 AI 软件开发全景：

\begin{enumerate}
    \item \textbf{Week 1}：LLM 基础与 Prompting 技术——理解 AI 编程工具的底层能力
    \item \textbf{Week 2}：Coding Agent 与 MCP——构建和标准化 Agent 的工具接口
    \item \textbf{Week 3}：AI IDE 与 Context Engineering——优化人机协作的上下文环境
    \item \textbf{Week 4}：Agent Patterns 与 Claude Code——管理多 Agent 工作流
    \item \textbf{Week 5}：Modern Terminal 与产品设计——AI 开发工具的七大产品原则
    \item \textbf{Week 6}：AI Testing \& Security——新型攻击向量与安全防护
    \item \textbf{Week 7}：AI Code Review——人机协作的代码质量保障
    \item \textbf{Week 8}：Automated UI/App Building——从自然语言到生产应用
    \item \textbf{Week 9}：AI DevOps/SRE——生产环境的智能运维
    \item \textbf{Week 10}：未来展望——AI 软件工程的下一个十年
\end{enumerate}

\begin{knowledgebox}{从编码到运维的完整生命周期}
这门课的独特价值在于它覆盖了软件开发的\textbf{完整生命周期}——不仅仅是``用 AI 写代码''，还包括测试、安全、代码审查、应用构建和生产运维。这反映了一个重要现实：AI 正在渗透 SDLC 的每一个环节。
\end{knowledgebox}

\subsection{本章小结}

十周课程勾勒出了 AI 软件开发的完整图景，从 LLM 基础能力到生产运维的每个环节都在被 AI 重塑。
