\section{Infraestructura y principios de DevOps}

\subsection{Las cuatro señales de oro del monitoreo}

\begin{importantbox}{Las cuatro señales de oro de Google SRE}
\begin{enumerate}
    \item \textbf{Latency}(latencia): tiempo de respuesta de las solicitudes
    \item \textbf{Errors}(errores): proporción de solicitudes fallidas
    \item \textbf{Traffic}(tráfico): solicitudes por segundo (requests/sec)
    \item \textbf{Saturation}(saturación): utilización de recursos; cuando se acerca al límite, el desempeño del sistema se degrada de forma abrupta
\end{enumerate}
Además, es necesario monitorear los traces(la cadena de rastreo de solicitudes)del entorno de producción.
\end{importantbox}

\subsection{Respuesta a incidentes en la práctica: el error 500 de base de datos a las 3:12 a. m.}

Cuando una alerta de PagerDuty muestra un aumento repentino de errores 500 en las consultas a la base de datos, el flujo de respuesta estándar (playbook) es el siguiente:

\begin{enumerate}
    \item \textbf{Confirmar y evaluar}(Acknowledge and assess)
    \item \textbf{Revisar la base de datos y la aplicación}(Check DB + app)
    \item \textbf{Identificar cambios recientes}(Identify recent changes)
    \item \textbf{Ubicar el alcance del impacto}(Localize blast radius)
    \item \textbf{Ejecutar medidas de mitigación}(Execute mitigations)
    \item \textbf{Estabilizar y monitorear}(Stabilize + monitor)
    \item \textbf{Comunicar}(Communicate)
    \item \textbf{Documentar}(Document)
\end{enumerate}

\subsection{Métricas clave}

\begin{itemize}
    \item \textbf{MTTR}(Mean Time to Repair): tiempo medio de reparación
    \item \textbf{Número de ingenieros que participan en el incidente}
    \item \textbf{Reportes de cumplimiento del SLA con el cliente}
\end{itemize}

\subsection{Resumen de la sección}

Las cuatro señales de oro (latencia, errores, tráfico, saturación) son el marco básico para monitorear sistemas en producción. La respuesta a incidentes sigue un playbook estandarizado, y las métricas clave son el MTTR y el alcance del impacto.
