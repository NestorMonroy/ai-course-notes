\section{总结与延伸}

Week 2 深入了 Coding Agent 的技术内核。从手动构建一个最小化的 Coding Agent，到理解 MCP 协议如何将工具集成标准化，课程展示了 AI 编程工具``魔法''背后的工程实现。

\subsection{关键要点}

\begin{itemize}
    \item Coding Agent = LLM + Tool Calling 循环，核心简单但工程细节决定质量
    \item Claude Code 的关键设计：context 前置加载、system reminders 防 drift、subagent 分流
    \item MCP 将 $M \times N$ 集成降为 $M + N$，使用 JSON-RPC 标准化工具描述
    \item MCP 架构：Host $\rightarrow$ Client $\rightarrow$ Server $\rightarrow$ Tool
    \item 当前局限：Agent 处理多工具能力有限，API 需要 AI-native 设计
\end{itemize}
