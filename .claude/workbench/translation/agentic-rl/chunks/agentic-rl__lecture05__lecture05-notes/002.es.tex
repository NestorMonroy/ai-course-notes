\section{Online vs. Offline 推理}
\subsection{Offline Batch Generation}
Adecuado para escenarios de procesamiento por lotes: se procesa de una sola vez un gran volumen de solicitudes para maximizar el throughput.

\subsection{Online Serving}
Se despliega como un servicio compatible con la API de OpenAI que admite solicitudes en tiempo real. Métricas clave: TTFT (latencia del primer token) y TPS (tokens por segundo).
