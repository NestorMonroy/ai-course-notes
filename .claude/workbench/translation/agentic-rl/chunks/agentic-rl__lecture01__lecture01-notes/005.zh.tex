\section{总结与延伸}
\begin{enumerate}
  \item RL 真正的目标是最大化期望奖励，PG Loss 只是代理
  \item 训练时关注 Rewards Curve 而非 Loss Curve
  \item PPO Clip 通过重要性采样比率和 clip 机制保证稳定训练
  \item veRL 框架提供了 Agentic RL Training 的完整 pipeline
\end{enumerate}
