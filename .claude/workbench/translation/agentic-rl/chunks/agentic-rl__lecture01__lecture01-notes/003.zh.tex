\section{定制化 veRL}
\subsection{主要定制点}
基于 veRL 做 Agentic RL Post-training 时，主要定制几个部分：
\begin{itemize}
  \item \textbf{Reward Function}：定义任务的奖励函数
  \item \textbf{Environment}：定义 Agent 交互的环境
  \item \textbf{Data Pipeline}：准备训练数据
  \item \textbf{Training Config}：调整超参数
\end{itemize}

\subsection{本章小结}
veRL 提供了灵活的定制接口，核心工作在于定义合适的 reward function 和 environment。
