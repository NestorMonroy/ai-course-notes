\section{工程防线：保证 token 与文本往返一致}
这节课揭示的是一个非常工程化、但足以毁掉训练的细节：如果 tool call 或工具返回结果在 decode/encode 往返中发生变化，训练上下文就会悄悄偏离原始轨迹。对多轮 RL 来说，这种偏差会在每一轮被进一步放大。

\begin{warningbox}{最值得建立的检查项}
\begin{itemize}
  \item 对关键格式串做 encode/decode 一致性测试
  \item 把工具返回文本的重新编码结果写入日志
  \item 对高风险 tokenizer 单独做回归测试
\end{itemize}
\end{warningbox}

\subsection{本章小结}
Tokenizer 的细节并不“底层到可以忽略”。在 Multi-turn RL 里，它直接决定了上下文是否稳定可复现。
