\section{Search-o1：在推理途中自主检索}

\subsection{长推理为何更容易出现知识缺口}

\videofigure{figures/search-o1-intro.jpg}{Search-o1 为大型 reasoning model 增加自主检索能力，使其在推理中按需补知识。}{00:46:56--00:48:02}

\videofigure{figures/reasoning-knowledge-gaps.jpg}{推理链越长，遇到陌生实体、公式、实验事实或跨领域知识的机会越多，早期缺口会持续传播。}{00:48:02--00:49:28}

大型 reasoning model 可能具有强演绎能力，却缺少完成某一步所需的事实。若模型用“perhaps”“might”“likely”一类模糊表达掩盖缺口，后续推理会在错误前提上继续展开。

\begin{importantbox}{Reasoning failure 不总是 reasoning 能力不足}
有些失败来自缺少知识，有些来自不会推理。Search-o1 的价值在于把两者分开：遇到知识缺口先检索，拿到证据后再判断模型是否仍不能完成推导。
\end{importantbox}

\subsection{为什么一次性 RAG 不够}

\videofigure{figures/standard-rag-limitations.jpg}{标准 RAG 通常只在开始时按原问题检索一次，无法响应推理途中才暴露的新问题。}{00:49:28--00:50:24}

原始问题往往无法直接表达真正的检索需求。例如多步化学题需要先识别中间产物，再查询某个反应性质；第二步的查询只有在第一步推理完成后才知道。

\begin{warningbox}{更多文档可能让 reasoning 更差}
把 top-$k$ 文档全部塞进 context 会引入冗余、冲突和长上下文注意力稀释。检索系统必须同时解决“何时搜”“搜什么”“保留什么”。
\end{warningbox}

\subsection{Agentic RAG 与 Reason-in-Documents}

\videofigure{figures/search-o1-framework.jpg}{Search-o1 在 vanilla reasoning 与一次性 RAG 之上加入多轮搜索和文档内推理。}{00:50:24--00:54:42}

可把第 $t$ 轮表示为：

$$
u_t=g(r_{\le t}),\quad
q_t=h(u_t),\quad
D_t=\operatorname{Retrieve}(q_t),\quad
z_t=\operatorname{Compress}(D_t,q_t),
$$

$$
r_{t+1}\sim p_\theta(\cdot\mid x,r_{\le t},z_t).
$$

\begin{itemize}
    \item $r_{\le t}$：当前 reasoning 前缀；
    \item $u_t$：模型识别到的不确定点或知识缺口；
    \item $q_t$：针对该缺口构造的搜索查询；
    \item $D_t$：检索到的原始文档；
    \item $z_t$：只保留与当前推理相关的压缩证据。
\end{itemize}

\videofigure{figures/agentic-rag-mechanism.jpg}{模型用特殊搜索标记暂停 reasoning、生成 query、调用检索器并把证据插回推理链。}{00:54:42--00:56:22}

\videofigure{figures/reason-in-documents.jpg}{Reason-in-Documents 模块独立分析检索文档，提取相关信息，避免长文档直接破坏主 reasoning chain。}{00:56:22--00:58:48}

\begin{knowledgebox}{压缩器本质上是信息瓶颈}
它既要保留足以支持下一步推理的事实，又要丢弃无关细节。压缩过度会漏证据，压缩不足会把噪声重新带回主模型。
\end{knowledgebox}

\subsection{Worked example：多步化学问题}

\videofigure{figures/search-o1-example.jpg}{在多步反应题中，Search-o1 先定位陌生化合物结构，再结合检索证据完成碳原子计数。}{00:58:48--01:00:34}

Vanilla reasoning 会对陌生化合物直接猜测；普通 agentic RAG 虽然取回文档，但长文本可能打断原推理。Search-o1 将流程拆成“发现缺口--查结构--提炼事实--继续计算”，因此最终答案更稳定。

\subsection{本章小结}

Search-o1 把检索从开场前处理改成 reasoning 内部动作，并增加文档压缩层。它解决的是长链推理中知识需求逐步显现的问题。
