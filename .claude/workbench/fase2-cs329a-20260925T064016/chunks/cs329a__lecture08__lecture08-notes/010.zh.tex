\section{总结与延伸}

本讲给出从 benchmark accuracy 走向 agent evaluation 的三层框架：

\begin{enumerate}
    \item \textbf{Capability span}：METR 用人类完成时间估计模型在给定成功率下能承担多长任务；
    \item \textbf{Economic usefulness}：GDPval 让行业专家直接比较 AI 与专业工作产品，并考虑重试、修复和审核成本；
    \item \textbf{Epistemic quality}：DeepScholar-Bench 检查来源覆盖、知识综合和 citation verifiability。
\end{enumerate}

最重要的结论不是“agent 已能做一小时任务”或“接近专家胜率”，而是能力增长呈现强烈条件性：

\begin{itemize}
    \item 50\% 成功率下的长任务，换成 80\% 可靠性后跨度会显著缩短；
    \item 有完整 prompt 的 benchmark 表现，不能代表真实环境中的 context acquisition；
    \item 视觉质量、指令遵循、事实准确和引用覆盖可能由不同模型分别占优；
    \item “可接受但不完美”的输出可以在低修复成本场景创造价值，却不适合高风险无人监督部署；
    \item 长时程进步必须伴随更好的状态管理、停止策略、错误恢复和 verifier。
\end{itemize}

最终，评估不是一张总榜，而是一套用于训练、路由和风险控制的诊断系统。下一讲将回到课程总主题：如何突破自我改进中的数据、验证与效率瓶颈，并探索 multi-agent fine-tuning、meta-verification、Absolute Zero 与 intelligence per watt。
