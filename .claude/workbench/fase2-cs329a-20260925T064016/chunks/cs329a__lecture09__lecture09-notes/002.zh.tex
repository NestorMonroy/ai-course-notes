\section{Multi-Agent Fine-Tuning：用多样 reasoning 延长自举}

\subsection{单模型 synthetic data 为什么会平台化}

\videofigure{figures/multiagent-finetuning.jpg}{Multi-Agent Fine-Tuning 用多个 generation agent 与 critic agent 产生、讨论并筛选 synthetic reasoning data。}{00:07:28--00:08:42}

\videofigure{figures/diversity-bottleneck.jpg}{单一模型反复生成自己的训练数据时，reasoning 逐渐同质化，迭代收益很快停滞。}{00:08:42--00:09:58}

Pretraining 数据由大量人类长期生成，天然覆盖不同文体、知识和思维路径；单一 LLM 即使提高 temperature，也常围绕少数高概率模板采样。Rejection sampling 只保留正确答案，会进一步压缩分布，造成 mode collapse。

可把第 $m$ 轮 synthetic data 分布记为 $q_m(r\mid x)$，若模型始终在自身输出上微调：

$$
q_{m+1}(r\mid x)\propto q_m(r\mid x)\,w(r),
$$

其中 $w(r)$ 是正确性或偏好过滤权重。若 $w$ 总偏爱已有高概率模式，低概率但有效的 reasoning 会逐轮消失。

\begin{warningbox}{Temperature 不等于语义多样性}
高温可能增加措辞和局部 token 变化，却未必产生不同解题策略。真正有用的 diversity 应在假设、分解、算法和证据路径层面测量。
\end{warningbox}

\subsection{Generation agents 与 critic agents}

\videofigure{figures/generate-data.jpg}{多个 generation agent 先独立作答，再汇总其他 agent 的答案并进入下一轮讨论。}{00:09:58--00:10:56}

\videofigure{figures/finetune-generators.jpg}{Generation model 在与多数结果一致的高质量 prompt--response 对上继续微调。}{00:10:56--00:11:26}

\videofigure{figures/finetune-critics.jpg}{Critic model 学习区分一开始就正确的轨迹，以及经过讨论才被修正的轨迹。}{00:11:26--00:11:58}

设有 $N$ 个 generator，第 $t$ 轮回答为 $a_i^{(t)}$。系统把其他 agent 的回答摘要 $s_{-i}^{(t)}$ 和 critic 反馈 $c_i^{(t)}$ 加入下一轮：

$$
a_i^{(t+1)}\sim p_{\theta_i}
\left(a\mid x,a_i^{(t)},s_{-i}^{(t)},c_i^{(t)}\right).
$$

\begin{itemize}
    \item $x$：原始问题；
    \item $a_i^{(t)}$：第 $i$ 个 generator 当前答案；
    \item $s_{-i}^{(t)}$：其他 agent 观点的摘要；
    \item $c_i^{(t)}$：critic 对答案缺陷的反馈。
\end{itemize}

\videofigure{figures/multiagent-debate.jpg}{多轮 debate 让 specialized agents 相互暴露盲点，最后用 majority vote 产生训练标签。}{00:11:58--00:13:08}

\begin{importantbox}{多 agent 的收益来自差异化 inductive bias}
若所有 agent 是同一 checkpoint、同一 prompt、同一 decoding 设置，它们会共享失败模式。需要通过数据子集、角色、超参或模型族制造稳定专长。
\end{importantbox}

\subsection{多样性与持续改进结果}

\videofigure{figures/diversity-results.jpg}{Embedding dissimilarity 显示 multi-agent 方案在多轮微调后仍能维持更高回答多样性。}{00:13:08--00:13:38}

\videofigure{figures/multiagent-results.jpg}{在多个开源模型上，multi-agent fine-tuning 随迭代继续提高准确率，而 single-agent 方案更早平台化或下降。}{00:13:38--00:14:08}

\videofigure{figures/generalization-results.jpg}{多 agent 生成的 reasoning 不只改善训练域，也在相邻数学 benchmark 上表现出迁移。}{00:14:08--00:15:02}

\begin{knowledgebox}{需要同时监控 performance 与 diversity}
准确率上升但 embedding diversity 快速下降，可能意味着系统正在透支未来探索空间；diversity 很高但准确率不升，则可能只是产生无效噪声。二者应构成 Pareto frontier。
\end{knowledgebox}

\subsection{本章小结}

Multi-Agent Fine-Tuning 用 specialized generators 扩大 reasoning 分布，用 critics 和多数投票控制质量，从而缓解单模型 synthetic data 的同质化与迭代平台期。
